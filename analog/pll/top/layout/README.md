# PLL 顶层版图入口

**当前只有摆位草案，没有当前 r6 完整布线宏及其提取网表。** [总审阅](../../../../docs/layout/pll_review_20261115.md)连接各子模块结论；CP、LDO 和 Bias 不在这次审阅范围。

[规划脚本](plan_pll_floorplan.py)读取已安装子块的实际外框与端口，输出 [规划图](pll_r6k4q_floorplan_plan.png)和 [带输入哈希的坐标表](pll_r6k4q_floorplan_plan.json)。尺寸标签由几何计算，不再保留过时的 ÷8／接收器尺寸。它仍引用 `r6_pdk` 的大环＋外置 buffer，**不是** VCO 新 `sym9` 内嵌 buffer 核的集成方案。

当前草案把反馈接收器放在右侧，PFD 在左侧；反馈引脚曼哈顿距离超过 500 µm。÷8 已缩小后仍沿用旧位置，留有明显空白。后续应围绕最终 VCO/÷8/反馈接收器更新摆位，使反馈接收器靠近 PFD、CP/LF 控制端朝向 VCO，并核对实际回流；不先按旧图画长反馈线。四个 buffer 输出的真实负载与三路轻 dummy 必须一并保留。

`pll_core_r6k4q.mag` 等根目录导入文件是旧草案。颜色表示电源域，不证明衬底隔离、护环或独立地已实现。箭头不代表实际线路，不能用本图面积、箭头长度或单元 DRC/LVS 推定整核性能通过。
