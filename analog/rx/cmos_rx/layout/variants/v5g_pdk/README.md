## Key 5G Architectural & Physical Features

- **0.0% M5 Usage**: Strictly M1–M4 + MIM1 (`cap_mim_m3_1`), leaving M5 completely open for chip-level power/shielding.
- **Cardinal Port Orientation** (`serdes_rx_cmos_pi_8ph_5g_pdk`):
  - **West**: `c0..c7` (2.5 GHz anchor clocks, 1.86–1.88 fF matched CPEX), `rst_n`, `vdd`, `vss`
  - **South**: `a0..a7`, `b0..b7`, `f0..f7` (grouped static 64-code CDR controls)
  - **North**: `ckd0..ckd3`, `cke0..cke3` (1.25 GHz quarter-rate outputs on uniform 16.0 µm pitch)
  - **East**: `dp`, `dn`, `ep`, `en` (quadrature-interleaved equal-span M4 stitch, 26.3–27.4 fF matched CPEX)
- **5G Sizing & Hierarchy Highlights**:
  - `serdes_rx_qdiv2_8ph_5g_pdk`: 3-stage reset delay chain (`Xrst` 2.0/8.0 → `Xrst_d1` 0.6/1.5 → `Xrst_d2` 1.2/3.0 driving dedicated `rst_n_lat`/`rst_lat` rails), 2.5 GHz TG clock gates (`wn=2.60/wp=6.80`, `Xinv 1.50/6.30`, `Xg 2.10/8.82`), SVT `0.42/0.28` latch keepers, fanout-matched latch outputs (`Xld0/1` `3.40/14.28` `nfn=2/nfp=4`, `Xle0/1` `1.45/6.09` `nfn=1/nfp=3`), and `2.40/10.08` output buffers with `0.45/1.89` CC aligners.
  - `serdes_rx_pi_rotator_5g_pdk`: `1.70/6.80` LVT input buffers, `1.60/4.20` (`nfn=2/nfp=2`) TG muxes + `2.00/8.80` drivers, `0.55/2.30` mixer slices with `l=7.2` `res_high_po_0p69` resistor banks, 3D-stacked `3.1×3.1` `Xcmix` + `4.1×4.1` `Xcac` MIM1 capacitors (`mixp/mixn` CPEX = 7.71–7.82 fF across all 4 nodes), vertical `l=10.5` `res_high_po_0p35` feedback resistors, and `1.85/7.40` → `2.80/11.20` LVT recovery buffers.
- **Reduced-RC Audit (`--rc`)**: `serdes_rx_qdiv2_8ph_5g_pdk` passes strict unmodified `review_cell.py --rc` (`rc_devices_preserved=True`). `serdes_rx_pi_rotator_5g_pdk` and `serdes_rx_cmos_pi_8ph_5g_pdk` preserve 100% of W/L/ad/pd, connectivity, and resistor subnetworks (only the 2 shorted `D=S=B=vdd/vss` dummy MOS-cap `as/ps` attributes differ under Magic `extresist`, audited identically to `v2p3_pdk`).

## Installed Artifacts

Each macro (`serdes_rx_qdiv2_8ph_5g_pdk`, `serdes_rx_pi_rotator_5g_pdk`, `serdes_rx_cmos_pi_8ph_5g_pdk`) has:
- `<cell>.mag` — flat SKY130A Magic layout
- `<cell>.png` — rendered layout plot
- `<cell>_ref.spice` — flattened LVS reference from `rx_cmos_pi_5g_cand.spice`
- `<cell>_lvs.spice` — Magic extracted LVS netlist
- `<cell>_pex.spice` — Magic extracted coupled-C + device AD/AS/PD/PS netlist
- `summary.json` — full machine-readable signoff report

All scratch files, Magic/Netgen logs, `.ext`, `.sim`, and `_rcx.spice` live under `results/layout/rx_cmos_5g/pi/`.
