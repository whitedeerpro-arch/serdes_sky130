# 63/0跨圈测试协议

2 GHz、1 UI=250 ps。两个差分时钟同时检查。初态码62：A=0、B=7、nB=2。使用20 ps外部控制斜率。

依次施加：62→63（nB=1）→0（nB=0，B暂留7）→空闲B改为1→1（nB=1）→2（nB=2）→1→0→空闲B改回7→63→62。

细码事件在t=3..10 ns加固定偏移，空闲B切换在4.5/8.5 ns加同一偏移；空闲支路各留500 ps恢复/建立时间。两个偏移分别267 ps（避开输出过零）和204 ps（接近码0数据时钟上升过零）。结束13 ns，最大步长2 ps；1 ns调相节奏是瞬态压力测试，不代表最终CDR更新率。

检查t≥2 ns后正负过零数量、相邻周期、两种极性脉宽、摆幅及共模。有限窗口内无额外/缺失过零与无窄脉冲，只支持本次规定序列。真实译码器、使能重定时、亚稳态防护和全扇区双向更新仍需单独设计与验证。

测试不是软件对输出波形做平移：外部PWL只驱动实际MOS选择/电流控制端，时钟输出由晶体管电路计算。没有完整数字CDR，也没有恒定ppm频偏下的长期闭环跟踪结论。
