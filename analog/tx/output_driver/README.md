# CML外部线驱动

这是芯片I/O输出级，驱动封装与PCB，不是让片内串化树直接承受50Ω负载。
路径为小输入隔离buffer→较强预驱动→大电流差分输出对；前两级承担门电容驱动，输出级承担线负载。

端口为inp/inn、CMOS tx_en、qp/qn、外部vbias、独立vdd_pre/vdd_out及vss。
tx_en=0断开线尾管偏置并下拉其栅；预驱动仍有静态功耗。两只源端50Ω为输出直流通路和源端端接。
远端另外两只50Ω接接收端共模，差分总负载100Ω。AC电容隔直流共模，不隔离交流负载。

当前器件W：隔离12µm、预驱动48µm、输出对256µm、尾管172µm；由实际偏置决定电流，非理想8mA源。
存在明确偏置、门/漏寄生与输出阻抗。供电分端口不等于已验证电源隔离，当前理想电源不包含共地电感/IRdrop；
真实版图还需安排回流、电源去耦和偏置分支。输入电容为工作点相关的有效电容，不能当作全PVT的固定值。

用户确认的初版接口为AC耦合、100Ω差分、远端400mVpp。配置见config/tx_line_driver.toml。
通道是16段被动RLC代理，不是PCIe规范或实测板线。FFE目前旁路，未实现1UI延迟数据或自适应系数。
设计边界和结果见[输出级与路线](../../../docs/history/tx_output_stage_and_link_plan.md)。
