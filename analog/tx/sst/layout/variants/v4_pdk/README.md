Key parasitic observations:
- **Pad output capacitance**: `pad_p = 46.53 fF` / `pad_n = 42.86 fF` across all 28 tiled slices + symmetric center-seam M4/M5 trunks (`ΔC = 3.67 fF`, well below the 100 fF 4 Gb/s pad budget).
- **`vdrv` bus RC**: Collinear `Xldo.vdrv` feed (`y = 74.75 µm`) into parallel M4 (`2.2 µm`) + M5 (`2.2 µm`) spine and full-width `2.0 µm` M5 over-straps directly over both `1.2 µm` M4 slice array rails (stitched with `via4` every 3–4 slices) cuts end-to-end slice-array `vdrv` sheet resistance ~5.5× (`8.16 Ω -> 1.47 Ω`, `R_sq(M4) ≈ 0.079 Ω/sq`, `R_sq(M5) ≈ 0.029 Ω/sq`) and keeps every branch below Magic's `1 Ω` `extresist` threshold (`0` extracted wire resistors on `vdrv`, `pad_p`, `pad_n`).
- **Serializer clock/data interface**: `phi0..phi270 = 14.18 / 14.27 / 15.04 / 15.58 fF` at top (combining compact serializer `3.50–4.30 fF` + driver `1.91–2.69 fF` + shortened flush-West `1.30 µm`-pitch M3 corridor exit), `d0..d3 = 13.69 / 14.17 / 14.16 / 10.21 fF` (`ser`) + `11.56 / 13.24 / 12.16 / 13.66 fF` (`drv`), `db0..db3 = 10.77 / 8.93 / 9.22 / 6.28 fF` (`ser`) + `11.10 / 11.66 / 12.64 / 11.81 fF` (`drv`), `clk500_out = 3.42 fF`, `clk250_out = 3.40 fF`.

## Architecture & Floorplan Notes

1. **`sst_slice_unit_pdk`**: `8.80 µm` abutment-tiled unit cell (`2× sst_nand2 + 2× sst_inv` local pre-drivers, symmetric `3.8/0.15 nf=2` LVT NMOS pull-up + `2.6/0.15 nf=1` LVT NMOS pull-down, matched `sky130_fd_pr__res_high_po_2p85 l=3.75` single-bar resistors inside a continuous p-sub guard ring, and exact-width horizontal M3/M4 rails).
2. **`sst_vdrv_ldo_pdk`**: Compact `1.8 V -> 0.44 V` sub-regulator (`86.50 × 88.62 µm`, `AR = 0.98`, flush West edge `xmin = 0.000`) using 3D stacked placement — `6× 24.8×24.8 µm` stacked MIM1+MIM2 (`15.3 pF` `vdrv` bypass bank, `pillar_side="none"`) directly over the 4 head-R-consistent single-bar `sky130_fd_pr__res_high_po_1p41` resistors (`l = 63, 37, 38, 80 µm`, 0% head-R error), one shared central `via34_pillar` (`x = 63.0, y = 48.0`) joining both MIM outer plates onto a collinear `yb3 = 2.90 µm` M3 VSS rail, 1:1 vertically aligned ABBA common-centroid 5T PMOS-input OTA (`5.20 µm` pitch), `17×17 µm` stacked MIM1+MIM2 (`1.2 pF` compensation cap routing `vgate` straight North on M4 over the M4-free OTA), and single-row wide `w=7.5, l=0.15, nf=32, m=1` LVT NMOS pass FET with collinear `D (vdd)` at `85.40 µm` and `S (vdrv)` at `74.75 µm`.
3. **`serdes_tx_sst_driver_pdk`**: Places compacted `Xldo` West (`x in [0.0..86.5]`), 2 compacted high-speed CMOS rows (`Xpg` on Row 0; `Xmux_m` + `Xmux_f` side-by-side on Row 1) East-South, and a 2×14 face-to-face mirrored SST slice array (`23` Main + `5` Post-FFE) East-North (`231.50 × 90.08 µm`, `20,853.5 µm²`) with collinear `Xldo.vdd`/`vdrv` ties, `2.0 µm` M5 `vdrv` slice over-straps, spread East enable pins (`y in [22.1, 32.9]`), and symmetric East M4+M5 `pad_p/pad_n` trunks.
4. **`serdes_tx_sst_serializer16_pdk`**: 5 mirrored standard-height (`9.50 µm`) static CMOS rows (`1 GHz` `/2, /4` dividers + 16:4 mux tree + 4-phase stagger retimers) with shared VDD/VSS seams, over-cell M3 routing (`227.98 × 51.62 µm`), Row-2 clock group (`Xc0..Xc27b`, `Xb500/Xdiv500`) aligned directly beneath shifted Driver `phi0..phi270`, continuous well taps, West VSS / East VDD spines, direct M4 South `din0..din15, rst_n, clk500_out, clk250_out`, and North `phi0..phi270, d0..db3` aligned `0.000 µm` 1:1 with the driver's South pins when placed at `dx = +4.20 µm`.
5. **`serdes_tx_sst_top_pdk`**: Stacks `serdes_tx_sst_driver_pdk` directly North of `serdes_tx_sst_serializer16_pdk` (placed at `dx = +4.20 µm` for an exact flush West edge `x = 0.000` and zero SE notch) across a compact `5.8 µm` inter-macro corridor (`y in [-6.20, -0.40]`; `d0..db3, phi0..phi270` join straight vertically on M4; `phi0..phi270` tap cleanly West on M3 at `1.30 µm` pitch / `0.86 µm` gap; `vss` and `vdd` bridge cleanly on M2 with zero crossings), reaching `231.50 × 146.98 µm` (`34,025.9 µm²`, `AR = 1.58`, `-8.4%` vs v4.1 `37,161.6 µm²`, `-31.3%` vs baseline `49,496.3 µm²`). All 38 top ports sit on the outer perimeter matching `serdes_tx_sst_top` 1:1.
