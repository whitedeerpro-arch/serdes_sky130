# 偏置与参考

> **当前状态**：各模块的电流镜、二极管和本地偏置都是真实 MOS；**最上游的绝对参考电流全部由理想源提供**，没有带隙或电流基准。
> **关键数字**：全局 CML 参考 0.85 mA；CP N/P 参考各 50 µA；CTLE 参考 50 µA。
> **主要缺口**：主参考与启动电路、分配与 trim、RX 共模参考/缓冲、LF 预充参考/缓冲都未设计；PVT 结果不含参考自身的变化。

## 偏置清单

| 偏置 | 用途 | 产生方式 | SS/1.65 V：−40 → 85 °C |
|---|---|---|---|
| `vbias` | VCO、CML buffer、时钟接收器、分频输入源跟随下拉；TX/PI/采样同类 | 理想 0.85 mA 注入 W/L = 20/0.5 µm 普通 NMOS 二极管 | 1.060 → 1.098 V |
| `vbias_logic`（PLL） | 宽尾管分频锁存器 | 复制全局参考约 1/6，经真实 N/P 镜注入本地 NMOS 二极管；每条 prescaler 一份 | 0.818 → 0.779 V |
| `vbias_logic`（TX） | 串化器 MUX/锁存器宽尾管 | `serdes_tx_logic_bias`，参考比例 1/6；每棵树一份 | — |
| `vbn` | CP 下拉 | 理想 50 µA 注入 W/L = 5/1 µm NMOS 二极管 | 0.903 → 0.893 V |
| `vbp` | CP 上拉 | 理想 50 µA 从 W/L = 20/1 µm PMOS 二极管抽取 | 0.267 → 0.412 V |
| CTLE `vbias` | RX CTLE 的 LVT 电流支路 | 理想 50 µA 注入 W/L = 8/0.5 µm LVT 二极管 | 0.719 → 0.675 V |

TT/1.8 V/27 °C 下全局 `vbias` 约 1.040 V，PLL `vbias_logic` 约 0.771 V。恒流下 VGS 本来就随器件和温度变化，所以偏置不应稳成固定栅电压。同名 `vbias` 在不同夹具里可能对应不同器件与参考电流，CTLE 的 LVT 偏置不能接 CML 全局栅偏置。

电压目标另列：RX 端接共模名义约 0.9 V；LF 预充目标名义约 1.40 V（可校准，峰值电流约 2.6 mA）。`Vctrl` 是 PLL 动态输出，不是基准。

来源：[偏置与 buffer](../history/serdes_bias_inventory.md)、[数据](../data/ss_buffer_bias.json)。

## 灵敏度观察

- 只对分频级间 buffer 的栅偏置加 ±50 mV，SS 冷热四个测点仍正确 ÷4（离散点，不是已签核容差）。
- 全局 Iref 改为 0.68 / 0.85 / 1.02 mA 会同时改变上游 buffer、源跟随器和本地尾源：SS 热角 0.68 mA 时上游 ÷2 已失去摆幅；1.02 mA 时 SS 冷角后级尾管平均余量只剩约 +14 mV。增流不是免费的。

## 建议结构

```text
主参考与启动电路
  → 可调参考电流与分配
    → VCO / CML buffer 本地偏置
    → 低过驱动分频/串化尾源偏置
    → CP 的 N / P 匹配参考
    → CTLE 的 LVT 专用参考
  → 电压分配与缓冲：RX 共模、LF 预充目标
```

先定电流及温度系数、压差、启动、可调范围，再选带隙/亚带隙结构。VCO 偏置要与高速逻辑偏置总线隔离，考虑分配噪声、时钟回灌和去耦。
