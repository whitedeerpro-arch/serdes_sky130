# 偏置与参考

> **当前状态**：各模块的电流镜、二极管和本地偏置都是真实 MOS；**最上游的绝对参考电流全部由理想源提供**，没有带隙或电流基准。
> **关键数字**：全局 CML 参考 0.85 mA；CP N/P 参考各 50 µA；CTLE 参考 50 µA。
> **主要缺口**：主参考与启动电路、分配与 trim、RX 共模参考/缓冲、LF 预充参考/缓冲都未设计；PVT 结果不含参考自身的变化。

## 灵敏度观察

- 只对分频级间 buffer 的栅偏置加 ±50 mV，SS 冷热四个测点仍正确 ÷4（离散点，不是已签核容差）。
- 全局 Iref 改为 0.68 / 0.85 / 1.02 mA 会同时改变上游 buffer、源跟随器和本地尾源：SS 热角 0.68 mA 时上游 ÷2 已失去摆幅；1.02 mA 时 SS 冷角后级尾管平均余量只剩约 +14 mV。增流不是免费的。

误差放大器与参考缓冲的指标分解见 [参考放大器](ref_amp.md)。

### 结论与建议

1. **参考电流按恒摆幅定义：I = m·Vbg / R，R 用与 CML 负载同类、同几何单元的 high_po。** 摆幅 I·R_load = m·Vbg·R_load/R 与电阻角（±12.5 %）和电阻温度系数无关；尾电流随之变 ±12.5 %。顺带：CP 电流同样定义时 Icp·R_lf 不随电阻角变（环路带宽稳定）。代价：R 偏高（hh）时 R·C 时间常数变大 12.5 %，CML 速度裕量在 SS + hh 下要重验——新的 PVT 维度是 MOS 角 × 电阻角（库里有 `ss_hh` 等组合段）。短电阻接触头使温度系数随长度变，负载和参考用同一种单元拼接。
2. **带隙核心：PNP（Kuijk 型），误差放大器用普通 nfet 输入，接在两支路电阻的同一抽头上。** 抽头位置 = 从 VBE 往上约 1/3 的 (Vbg − VBE)，输入共模 0.80–1.0 V，普通 nfet 在四角 × −40…85 °C 都满足 Vgs + 尾管 ≤ 共模；抽头使放大器失调到 Vbg 的增益乘约 1.5，但 nfet 的 A_VT 是 pfet_lvt 的 1/3.6，等面积下仍更好。输入在 VBE 上的两种做法都不可行：PMOS（即使 LVT）在 SS 冷角共模上限不够、NMOS 在热角共模下限不够。
3. **失调是 Vbg 的主误差，计划带修调。** 失调增益约 (1 + K)·1.5 ≈ 17（N = 8）；N 取 24 时 K ≈ 6.8，失调增益约 12。σ_os = 1 mV 对应 Vbg 约 1–1.4 %；靠面积压到可忽略要几百 µm²。每颗芯片的失调是静态的，修调（如 4 bit、±5 %）可去掉；MC 用来定修调范围，修调后残差 = 步长 + 温漂。
4. **V→I 用第二个放大器**（输入在 m·Vbg 上，NMOS 输入）：直接把 1.245 V 放在电阻上，1.65 V 下 PMOS 镜 + NMOS 的余量不够，取 m ≈ 0.5（电阻分压，比例精度）。该放大器的失调对电流的影响约 σ_os / (m·Vbg)，1 mV 时约 0.16 %。
5. **电压参考**：vcm 1.05 V = 0.843·Vbg（分压）经单位增益缓冲 B1（NMOS 输入）；LF 预充 1.40 V 由 I·R（比例）生成后经缓冲 B2；两者都只驱动高阻 / 去耦负载（预充窗口放宽到约 1 µs，见上文讨论），不需要推挽输出级。
6. **分配**：电流模式送到各模块，本地二极管产生栅偏置，偏置线 RC 去耦（噪声，P4）；VCO 偏置与高速逻辑偏置分开。启动电路排除零电流态。VCO 供电 LDO 等 P4 结论。

```text
PNP 带隙核心（Kuijk，nfet 输入接抽头，修调 R2/R1）── Vbg ≈ 1.245 V
  ├─ 分压 m·Vbg → V→I（放大器 + NMOS + R_ref，high_po 单元）→ I_ref ∝ Vbg/R
  │     → PMOS 镜分配：VCO / CML / logic 尾偏置、CP N/P、CTLE（各自本地二极管）
  ├─ 分压 0.843·Vbg → 缓冲 B1 → RX 端接共模 1.05 V（中心抽头去耦）
  └─ I_ref·R → 缓冲 B2 → LF 预充 1.40 V（约 1 µs 窗口）
启动电路；修调寄存器
```

待定的选择：N = 8 还是 24；修调位数和范围；m；CML 尾电流的 ±12.5 % 在 ll 角下的尾管余量。
