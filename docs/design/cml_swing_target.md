# CML 的400mV目标与内部幅度范围

**400mVpp适合作为初始驱动目标，现有证据不足以把它当成所有内部节点共同的物理失效上界。** 当前复核内部上界的适用性，尚未采用替代数值；原始波形、仿真前400mV约束及历史评分继续保留。眼图、换向、器件余量与应力分别判断，I-17不因此关闭。

## 小摆幅与速度的关系

对充分换向、两侧相同电阻R且没有额外直流负载的电流舵单元，尾电流为I时：

`单端峰峰值 = I R；差分峰峰值 = 2 I R；共模 = VDD − 差分峰峰值/4；最低漏极 = VDD − 差分峰峰值/2。`

因此差分400→436mVpp只使这一理想情况下的共模下降9mV、最低漏极下降18mV。是否耗尽某只堆叠管的余量要看其实际源极、VDS−VDSAT、输入共模及负载；这个公式本身推不出400mV硬上界，也不能直接套在未充分换向、动态再生或有额外直流负载的节点上。

“小摆幅有利高速”的想法有依据，但要明确怎样减小：

| 改动 | 简化模型中的收益 | 同时变化的约束 |
|---|---|---|
| 固定尾电流，降低R | RC极点变快，电压下拉较少 | gmR和输入噪声余量降低；静态VDD·I不降低 |
| 固定R，降低尾电流 | 静态功耗降低，电压下拉较少 | gm与I/C下降，但所需电压行程也下降；不保证更快，也不能仅凭I/C断言更慢 |
| 改输入对宽度WN或电流密度 | 可改善弱输入下的增益/换向 | 输入与内部电容、上一级负载、失配和延迟一起变化，须联合优化 |

理想完全换向的单极点单元满足`RC·dy/dt+y=I R·sign(vin)`。以IR归一后，50%响应约为`RC ln2`，与I无关。这说明仅降低电流并不自动提高速度；实际还受有限gm、换向压差、非线性电容及再生约束。输出电压噪声引起的交越抖动近似为`σv/|dV/dt|`，减幅时也要检查噪声与slew。

[低压高速CML缓冲器分析](https://cecs.uci.edu/~papers/compendium94-03/papers/2003/glsvlsi03/pdffiles/2_2.pdf)讨论了负载、偏置及输入共模对带宽/工作区的共同限制；文中电压符号不能直接当作本项目的差分峰峰值。[CML发射机电路优化研究](https://pure.skku.edu/en/publications/power-performance-tradeoff-analysis-of-cml-based-high-speed-trans/)也把级间摆幅和边沿速率作为联合优化量。这些资料提供方法，不提供SKY130的400mV数值签核。

## 当前测量支持什么

- 分级尾宽完整TX的SS冷角extra最高435.89mVpp，但串化器/焊盘散布0.04023/0.05188UI，眼图满足。它偏离旧目标，尚没有“436mV造成性能失败”的证据。
- [末级需求卡](tx_retime_demand.md)SS八点的眼图/位序均满足，差分×1.1的两个输入为424.45mVpp。原200–400mV筛查仍记越界，当前不单凭此数淘汰。
- 同一个分级尾宽候选在FS热角的焊盘散布为0.179857UI，仍是真实规格失败。五级统一减幅的FS裕量69.75mV、散布0.212UI也仍失败；上界复核不改变这些结论。
- 既有串化末级R400→330→270Ω实验使FS裕量121→88→39mV，未改善约18mV下垂或尾管余量。该处不能只靠减幅追求速度，见[串化器](tx_serializer.md)。

## 后续尺寸约束

按节点建立允许范围：时钟缓冲/接收器看换向、slew、附加抖动及负载；数据保持/MUX看相同位号的关闭、建立保持与中心裕量；输出级看接口目标和实际负载；VCO单独按相噪与调谐范围判断。

下一张单元卡须记录实际支路电流、输入/输出共模、上下沿slew、所有关键管的端电压与VDS−VDSAT，以及宿主扰动引起的数据/关闭相对延迟。与PVT、无源角、噪声/失配和模型留出误差联合求可行区，再确定各节点幅度范围。现阶段不以425或450mV之类新数字替换原上界。
