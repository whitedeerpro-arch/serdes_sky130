# PLL VCO r6 + BIAS v2 PTAT 尾流温补（独立候选）

**结论**：**不改动 `vco_ring4_r6` 与 `vco_delay_r6` 任何晶体管尺寸**，仅将 BIAS v2 内部既有的 **恒摆幅支路 `vgi`（`28` 指 `8/4` `pfet_lvt`）** 与 **带隙核心 PTAT 支路 `vg`（`66` 指 `14/6` `pfet_lvt`，约 67% PTAT 占比）** 混合送入 VCO 本地偏置二极管（[vco_ptat_bias.spice](../../analog/pll/vco/spice/vco_ptat_bias.spice)），在全部 **135 条件（5 MOS × 3 VDD × 3 T × 3 RC）** 下实现：

- **跨三温（`−40 / 27 / 85 °C`）单一共同码覆盖率：`36/45 → 45/45（100%）`**，每颗芯片均拥有 **≥ 2 个共同码**，最差窗口边缘裕量 **`+86.5 mV`**（中位数 **`164.9 mV`**）——**彻底取消运行期动态切码**，开机 5 步二分粗调即可覆盖全温程；
- **全温程最佳码漂移大幅收敛**：由 `+1..+5`（中位数 `3`、最大 `5`）压缩至 **`−1..+2`**（中位数 `1`、最大 `|2|`，最大漂移降 60%）；
- **慢/快端频率余量双向扩大**：慢端 `+8.23% → +11.93%`（`+3.70 pp`），快端 `+8.63% → +11.26%`（`+2.63 pp`），`min(window/LSB)` 由 `2.25 → 2.51`；
- **高温慢角差分摆幅大幅抬升**：`SF/SS/FS/FF 1.65 V 85 °C hh` 全部抬升 `+73..+80 mVpp`（`SF 85 °C hh` 由 `360..451` 升至 **`440..542 mVpp`**），直接验证的 33 个 2 GHz 锁定点摆幅全部 **`418–545 mVpp`（全过 ≥ 400 mVpp 目标）**；
- **尾管饱和裕量充裕**：全 135 角最差 `Vds − Vdsat = +220.6 mV`（`fs_v1650_t85:ll`，为 50 mV 门槛的 `4.4×`）；
- **常温功耗几乎不变**：TT 1.8 V 27 °C（VCO + 4 buf + bias）为 `11.82 mW`（相对基线 `11.74 mW` 仅 `+0.7%`），低温 `−40 °C` 反降 `13.3%`（`10.40 mW`），高温 `85 °C` 仅增 `13.0%`（`12.87 mW`）；
- **采用状态**：独立候选，**未替换** `config/pll_working_revision.toml`、`vco_ring4_r6.spice` 或 `bias_v2.spice`。

## 1. 物理根因与配比推导（`nf_const = 28`, `nf_ptat = 66`）

1. **原 r6 温漂根因**：在 BIAS v2 的 `rcorner.to_pdk_fixed` 标定下，恒摆幅支路 `vgi`（`8/4` `pfet_lvt`，TT 27 °C `2.50 µA/指`）受 `high_po` 参考电阻正温漂影响实际呈轻微 **CTAT**（`I(85 °C)/I(−40 °C) = 0.941`，`−5.9%`）。叠加高温 NMOS 迁移率下降，原 r6 高温频率比低温跌落 `6.7–11.3%`，导致 9/45 组芯片（7 组 `ll` + 2 组 `1.65 V tt`）缺失跨三温共同码，且高温慢角摆幅跌至 `350–360 mVpp`。
2. **免费利用 BIAS v2 既有 `vg` PTAT 支路**：BIAS v2 带隙核已有 `vg`（`14/6` `pfet_lvt`，TT 27 °C `2.184 µA/指`），其温度比为 `I(85 °C)/I(−40 °C) = 1.423–1.446`（`+43.4%` TT），且同样与 `1/R_high_po` 跟踪在 `±0.5%` 内。将其与 `vgi` 在偏置宏内部直接并联拷贝进 VCO 专用电流出口（TX/RX 的 `icml` 仍保持纯恒摆幅不变），零新增带隙或参考电路、高阻节点 `vg/vgi` 仍全封闭在宏内。
3. **弹性系数与一阶段预扫**：r6 实测尾流频率弹性 `E = (df/f)/(dI/I) ≈ +0.26`。在原缺失 9 组 + 8 压力角上预扫三档配比（`results/analog/pll/vco/r6_ptat/sweep_20261120T203723Z/sweep.json`）：`p45 (47/44)` 恢复 `6/9`，`p60 (34/58)` 恢复 `7/9`，`p75 (21/73)` 恢复 `9/9`。最终定型为平衡点 **`p67`（`nf_const = 28, nf_ptat = 66`）**：
   - TT 1.8 V 偏置输出 `I_cml`：`188.1 µA (−40 °C) → 214.2 µA (27 °C，对应 VCO 1.089 mA/级) → 233.9 µA (85 °C)`（`85/−40 = 1.244`）；
   - 已核对轻量瞬态核 `serdes_bias_vco_ptat_core` 与完整集成宏 `serdes_bias_top_v2_ptat` 的 5 位有效数字 DC 等价性。
