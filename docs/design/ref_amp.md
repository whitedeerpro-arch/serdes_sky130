# 参考放大器：带隙误差放大器 + 参考缓冲

> **当前状态**：指标分解（本文）。未设计电路。
> **用途**：(A) 带隙核心的误差放大器；(B) 电压参考缓冲：B1 RX 端接共模 vcm，B2 PLL 环路滤波预充目标。两者共用"偏置 + OTA"核心，B 另加能拉能灌的输出级。
> **同时作为尺寸设计流程的方法验证对象**（[sizing](../verification/sizing.md#缺口)）：先只跑 TT，记录迭代次数和每轮模型误差。

## 与 CML 电路的区别

速度几乎无关紧要，关键量是直流精度和低频特性：失调、增益、1/f 噪声、PSRR、容性负载下的稳定性，以及对 A 而言的启动行为。所以器件卡要在 gm/ID 表之外加 gds（本征增益）、噪声系数和失配（Pelgrom 系数）；失调指标需要 Monte Carlo，45 个 PVT 条件不含失配。

## 指标

来源：**规格** = 规格或模块文档直接给出；**推导** = 由上游数字算出（写明算式）；**暂定** = 中间指标，为未建模因素留余量，修改需写明理由。

### A. 带隙误差放大器

| 指标 | 值 | 来源 |
|---|---|---|
| 输入共模范围 | 约 0.55–0.8 V（VBE 在 85 °C 到 −40 °C 间的变化），1.65 V 电源下输入对和尾管保持饱和 | 推导（随带隙核心结构而定，建 PNP 卡后核实）；见下文"输入共模是结构约束" |
| 输出范围 | 覆盖驱动 PMOS 电流源栅极所需的区间（约 VDD − 0.4 V 到 VDD − 1.0 V） | 暂定，带隙核心尺寸定后改为推导 |
| 直流增益 | ≥ 60 dB | 推导：有限增益误差 ≈ Vbg/A ≤ 0.1 % |
| 失调（含随机，3σ）对 Vbg 的贡献 | ≤ 1 % | 暂定；输入失调预算 = 1 % · Vbg / G，G = 核心的失调放大倍数（约 1 + R2/R1），核心定后算 |
| 环路相位裕度 | ≥ 60°，带实际栅极负载与去耦电容 | 暂定（常规取值）；带隙环路有正、负两条反馈，负反馈必须占优 |
| 建立时间 | 上电后 ≤ 1 µs 到 0.1 % | 暂定（启动时序未定） |
| 启动 | 不存在零电流稳态（含启动电路） | 规格（功能） |
| PSRR、噪声 | 待 P4 抖动预算 | 待推导；见下文"噪声的路径" |
| 电流 | ≤ 50 µA | 暂定（PPA 排在功能之后） |

## 两条影响全局的线索

1. **参考电流的精度主要不由放大器决定。** 参考电流 = Vbg / R：多晶电阻的工艺偏差在 ±10–20 % 量级，远大于 Vbg 的 ±1–2 %。[偏置](bias.md#灵敏度观察) 实测全局 Iref 偏 ±20 % 时 SS 角失败。两种做法：
   - 限定电阻偏差（修调）；
   - 恒摆幅偏置：偏置电阻与 CML 负载电阻同类型，摆幅 I·R = Vbg · R_load / R_bias 与电阻工艺无关，剩下的误差主要是 Vbg 和比例失配。

   选哪一种决定放大器失调预算松紧，需要先建电阻工艺角卡（现有 45 条件只变 MOS 工艺角，负载电阻都是理想的）。
2. **噪声的路径。** 基准噪声 → 偏置电流 → VCO 尾电流 → 频率调制。PLL 环路（UGB 约 3–4 MHz）对环内的 VCO 噪声有抑制，所以影响大的是环带以外的频段，而偏置线上的 RC 去耦正好滤掉高频。初估：加偏置线滤波后，误差放大器的噪声不是瓶颈。数值以 P4 为准。

## 输入共模是结构约束

TT 器件卡，gm/ID = 15、|Vds| = 0.4 V 的 PMOS 输入对 |Vgs|：

| 器件 | −40 °C | 27 °C | 85 °C |
|---|---|---|---|
| pfet（L 1–2 µm） | 1.21–1.23 V | 1.06–1.08 V | 0.88–0.90 V |
| pfet_lvt（L 1–2 µm） | 0.66 V | 0.48 V | 0.34 V |

输入在 VBE 上时，−40 °C 需要 0.80 + |Vgs| + 尾管约 0.2 V ≤ 1.65 V，即 |Vgs| ≤ 0.65 V：普通 PMOS 输入（合计 2.2 V）任何尺寸都不行；pfet_lvt 在 TT 下正好压线，SS/FS 更差。所以误差放大器的输入不能直接放在 VBE 上，这是带隙核心结构的约束，和放大器一起定。候选：分压后接入放大器（亚 1 V 带隙类结构）；NMOS 输入对接在更高的节点上（需要可靠启动）；pfet_lvt 推到弱反型（余量很薄）。方法验证阶段（TT、理想偏置）不受影响。

## 候选结构（待约束比较）

| 候选 | 组成 | 适合 |
|---|---|---|
| T1 两级 Miller | PMOS 输入 5 管 OTA + 共源第二级 + Miller 补偿；偏置为电流镜 | A（增益足、输入共模低）；加推挽输出级后作 B |

方法验证阶段的偏置用理想参考电流；进入带隙后改由核心的 PTAT 电流供给，届时启动电路一并考虑。

## 计划

1. TT 器件卡（已建，噪声列未加）；验证 SKY130 Monte Carlo（`tt_mm` 段）在 ngspice 下可用。
2. 用器件卡写 T1/T2 的约束和粗模型，按 A 的指标求解，并给出代价。
3. TT 仿真（工作点、AC、瞬态、失调 MC）→ 校准 → 迭代到收敛；记录每轮误差。
4. 方法验证结论写入 [sizing](../verification/sizing.md)；然后进入带隙核心与 PVT（加电阻工艺角）。

## 适用范围与假设

- 输入共模、输出范围、失调放大倍数依赖带隙核心结构，核心定下之前按常见结构估计。
- 噪声、PSRR 指标在 P4 抖动预算推导前不设门槛，只记录。
- B2 的电流和建立要求来自现有 PLL 启动仿真（理想参考 + 500 Ω、40 ns 预充窗口），PLL 启动时序可改。
