# 从名义功能原型进入PVT与噪声验证

当前进展：[低过驱动分频器 r2](pll_lowov_pvt.md)已应用到工作网表，标准输入边界的分频/反馈完成 45 条件功能网格，全速 CMOS 44/45。真实 FS 低压热角仅在 1.927 GHz 恢复，2 GHz 回接仍待解决；不是全 PLL 的 45 点闭环签核。下面的首轮与独立候选章节保留为历史计划和演进记录。[锁存器结构调研及电路图](cml_latch_topology_review.md)列出后续比较方向。

2026-10-29。当前完成了名义条件下的前仿电路/功能原型和分层接口验证；尚未完成PVT、随机失配、噪声和版图寄生后的设计闭合。PLL/TX冻结是待独立资格验证的设计基线，RX还保留物理16UI降速/整字保持和数字时序边界，不将其视为全部模拟设计流程已经结束。

初版仅定义顺序和探索矩阵；后续已启动[PLL首轮PVT及物理滤波器候选](pll_pvt_first_results.md)。相位噪声方法尚未运行验证。参数定义在[角计划](../../verification/corners/pvt_plan.toml)，冻结电路和旧测试记录不修改。

## 顺序：先PVT功能筛查，再相噪，最后交叉验证

先确认各角能起振、调到2GHz，并有合理摆幅、共模、偏置顺从范围和采样裕量。电路若在角上失去正常工况，相噪比较缺少共同基准；后续为修复角问题改尺寸/电流，也会改变噪声结果。

不必等所有模块45个环境组合全部完成，才验证噪声方法。可在首轮名义工况和关键角筛查后，用同一版本的带载VCO验证方法；再测TT及PVT筛出的代表性不利工况。最差功能角未必是最差噪声角，最终仍须相应交叉检查。

## PVT矩阵和适用范围

第一轮探索采用MOS的TT/SS/FF/SF/FS，供电1.65/1.8/1.95V，温度−40/27/85°C，共45个环境组合。先做9个pilot：5种MOS角的1.8V/27°C，加SS/SF低压高温、FF/FS高压低温。它们是筛查点，不假定这几个点对所有指标最坏。

这是工程探索范围，尚不是产品温度/供电规格。选择1.95V而不直接采用1.8V+10%=1.98V，是因为标准1.8V MOS公开模型给出的VDS/VGS有效上限为1.95V；器件端电压和过冲仍需另查，供电不越界并不自动证明所有器件端电压合规。[SKY130器件模型范围](https://skywater-pdk.readthedocs.io/en/main/rules/device-details.html)

45个环境组合不等于45次仿真：每角可能还要扫描电容码、Vctrl、输入共模、负载或观察窗口。全网格留待pilot验证测试方法和指标后展开。

| 层次 | 复用内容 | 首轮收集 |
|---|---|---|
| 带载VCO/时钟接口 | 原生环振、四路对称抽出、真实buffer/转换/分频与powered dummy | 起振、f(Vctrl,code)、2GHz可达性、码段重叠、Kvco、摆幅/共模、功耗、÷8边沿 |
| CP/LF与PLL | CP输出电流扫描、PFD/CP/LF夹具、启动/跟踪测试 | 电流与顺从范围、UP/DN差异、控制电压余量；选角捕获/跟踪 |
| TX与输出级 | 冻结末级锁存设置、实际选择器/驱动与通道夹具 | 位序、中心错误、额外/漏跳变、UI散布、幅度、共模、功耗 |
| RX前端/PI/采样 | CTLE、PI64码、采样器、静态CMOS转换与pair重定时 | 增益/峰化、调相范围及步进、脉宽、判决/读出裕量 |
| 接口集成 | 已验证的隔离切点与实时RTL联调 | 选定关键角下的电平、负载和控制更新行为 |

VCO先保留原设计电流和尺寸，测未校准状态，再允许调电容码/Vctrl寻找2GHz，并记录余量。固定同一Vctrl时频率随PVT变化本身不等于PLL无法工作；若必须改尺寸或偏置才能达到目标，应记录为新设计版本，而不能当成原版PVT通过。

## 复用TB前需要补齐的内容

- 统一参数入口：已有多份TB支持模型库/工艺角替换，但温度、供电和部分激励仍硬编码；pilot前逐项参数化，不直接把TT字符串替成SS就认作完整PVT。
- 保留实际加载和对称dummy。起步使用[带载时钟前端](../../analog/pll/top/spice/clock_frontend_balanced.spice)，不把早期20fF代理负载的裸VCO图充作当前带载版本。
- 理想参考电流、共模参考和环路无源必须注明。PDK本机基本TT/SS/FF/SF/FS库段使用typical R/C；当前大量电阻和LF电容本身还是理想器件。MOS角不自动覆盖这些无源变化。后续独立做PDK无源角或有依据的参数扰动，不能称第一轮已验证全器件PVT。
- CMOS激励与复位幅度随VDD调整。RX理想CML锚点的共模/摆幅取同角带载输出或明确的接口条件；当前实时桥0.54/1.26V阈值对应1.8V，改供电时应按既定0.3/0.7比例更新，不直接沿用固定值。
- 全局工艺角与局部失配分开；PVT扫描不开Monte Carlo。独立的参考电流误差、电源扰动和负载压力也单列，不偷换为工艺角。
- 测量失败记为不可用，功能失败单列。未定义产品指标的量保持ungraded；仿真退出码为0不代表设计通过。

## 噪声与相噪的后续入口

相位噪声先从带实际抽出负载、已调到2GHz的VCO开始，再讨论PLL中参考、PFD/CP、分频/缓冲和VCO的贡献及环路整形。RX的CTLE输入参考噪声、采样器失调/判决噪声是另一支验证；普通无噪声瞬态的边沿散布不能直接记作随机抖动或统计BER。

现有[相噪case](../../analog/pll/vco/tb/phase_noise/case.toml)仍是planned，本机Xyce 7.10与SKY130噪声组合尚未验证。先用小电路核对模型兼容、器件噪声源、振荡器工作点与相位噪声提取方法；仅有HB或普通小信号NOISE命令不自动构成本项目已经验证的振荡器相噪流程。引擎功能以[本机版本对应的Xyce官方资料](https://xyce.sandia.gov/documentation-tutorials/)和实际方法检查为准，不从命令名推断结果有效。

结果需记录载波、单边dBc/Hz约定、频偏范围、积分带宽、噪声来源、步长/谐波或统计长度及收敛复核。在这些条件确认前，不给出已达标的积分抖动数字，也不用短窗FFT替代近端相噪测试。
