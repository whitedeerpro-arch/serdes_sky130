# TX 入口保持表征：激励与初态诊断

最终边界与结论维护在[当前模块设计](../design/tx_launch_hold.md)，本页只保留被替换的实验依据。主16位DUT及尺寸未因这些数值/激励问题改动。

| 尝试 | 现象与处置 |
|---|---|
| `hold_aperture/20261106T205400Z` / BC v1 | 长PWL直接传给`alter`超过参数数量上限；实际电压源停在初值。四个原样例被唯一交越检查拒绝。执行退出成功不能代表激励有效。 |
| `hold_aperture/20261106T205713Z` / BC v2 | 有界PWL简化与向量装载解决参数上限。短窗口在SS冷角截到B组尚未完成更新，Q比较约1.7 V错误；FS冷角MUX保留之前的内部状态，约8 mV差异。原样回放未达5 mV门槛，不进行这些组的平移结论。 |
| `hold_aperture/20261106T210129Z` / BC v3 | 保留前一完整字周期，以B透明状态确定初态，六角两方向全部校准，所需窗口最大误差3.07 mV。先校准后运行156个平移点。 |
| `hold_aperture/20261106T211227Z` | SS单独补扫的1 ns冒烟在恰好1 ns处因极小步长截断。疑似短窗终点与邻近PWL时间点的数值问题；将终点延到1.001 ns后通过，不据此判定带隙电路失效。仍要求至少完成1 ns，不取消冒烟。 |
| `hold_aperture/20261106T211416Z` | 两个SS上升方向补扫，原样校准均通过，−125 ps失败、−100 ps保持；冷角−125 ps还出现中间存储状态。最终全部12组夹住边界。 |

BC v1/v2保留以解释旧尝试；当前入口使用v3。源波形未改写，原始运行、失败和每次deck全部保留。ngspice的PWL参数装载格式参照[官方手册](https://ngspice.sourceforge.io/docs/ngspice-manual.pdf)；本机47版另以无PDK的小电路实际验证短列表、长向量以及电压源输出。
