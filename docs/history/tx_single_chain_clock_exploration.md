# TX 单链打拍时钟探索（未采用）

2026-10-30/31。目的：消除 TX 四路时钟取自三条独立 prescaler 带来的启动状态不确定（I-01）。做法是让 250M/500M/1G 都来自同一条分频链，再用 CML 触发器把每路重新打拍到选定的 VCO 相位上，2 GHz 走一个 clk→q 复制单元。电路与 bench 在 `analog/tx/clock_distribution/{spice/tx_clock_retime.spice, tb/single_chain/}`，结果在 `results/analog/tx/clock_distribution/single_chain/`。

**结论：方向可行，但没有必要。** 后续分析发现，分频器状态错误只会让每个字的位发生固定重排，眼图完好（见下文"误判"），所以改为原时钟方案 + 启动状态检测 + 输入侧调序。本页保留探索中测到的电路事实。

## 测到的事实

| 项目 | 结果 |
|---|---|
| 分频链抽头跨 6 个压力工况的漂移 | ÷2 / ÷4 / ÷8 翻转时刻相对 VCO 相位 0 分别漂 75 / 165 / 255 ps；相邻级相对漂移约 ±50 ps |
| 照搬分频器尺寸的打拍触发器（保持管 W80、600 Ω） | clk→q 从 TT 的 114–127 ps 涨到 FS/1.65 V/85 °C 的 167–226 ps；1 GHz 输出在 FS 热角只剩 218 mVpp |
| 保持管减到 W20 | clk→q 约 53 ps，TT→FS 热角只增加 0–25 ps |
| 负载降到 400 Ω | 摆幅不足，采错沿，不可用 |
| 触发器时钟输入负载 | W80 源跟随对很重：一个抽出 buffer 挂 3 个，摆幅 457→295 mVpp，延迟 +65 ps |
| FS 热角采样建立时间 | 58 ps 不够（推迟一个 2 GHz 周期才采到）；按 ≥ 130 ps / 保持 ≥ 40 ps 选相位 |
| 同相位串联两级打拍 | W20 触发器 clk→q 只有 33 ps，第二级在同一沿上发生保持竞争、亚稳 |
| 大 RC trim（> 0.5 pF/端） | 真实源边沿本来就慢，FS 热角 1 GHz 选择时钟降到 247 mVpp / 211 ps，眼图只剩 61 mV |
| MIM 电容密度 | 2.0 fF/µm²（工艺角 1.78–2.23）；r2 原 trim 合计约 2.1 pF ≈ 1000 µm² |

## 误判与教训

整个探索用的是"按固定位序比对"的检查（`serial.check`）。之后用不依赖位序的 `serial.bit_mapping` 重新分析，结果如下：

- 时钟极性错、500 MHz 错开一个 VCO 周期等运行，眼图都在 145–158 mV，只是位重排。
- 当时判为"热角失败"的运行，以及 1 GHz trim 扫描中的"失败"点（FS 热角下 89–122 mV），大多也是干净的重排。

所以"FS 热角时序窗口很窄"是检查方法造成的假象。实际的电气窗口很宽，只是不同区间对应不同的位映射。

教训：涉及时钟相对关系的实验，要把"眼图健康"和"位映射"分开测，并且先量容差窗口再设计。
