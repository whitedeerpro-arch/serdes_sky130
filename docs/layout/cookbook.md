# 版图手册：规则数值、套路、流程

给辅助画版图的 agent。任务和验收见[任务单](tasks.md)，检查工具见[check.py](../../verification/layout/check.py)。本页讲**怎么画对**：先查数，再套路，按流程一步一检。

初次接手的DeepSeek/其他执行者先读[有正反例的入门教材](deepseek_training.md)；[DS-01工作单](training/DS-01-inverter.md)可直接派发，在独立教学目录练习，不改当前生产版图。

## 0. 已经踩过的坑（先读）

| 坑 | 后果 | 规矩 |
|---|---|---|
| 生成器调用前 `units microns` | 阱和保护环按默认 W 画，PMOS 在 N 阱外 | 生成器前不改单位；新脚本用 `magic::gencell` |
| 检查器没等 DRC 跑完就计数 | 255 个错误报成 0 | 只信检查器的三行输出和退出码 |

| 用公式自己推电阻值 | 公式错一项，整列数都错（“779.8 Ω 地板”是误读模型卡） | 阻值只用 Claude 给的、经 ngspice 实测的值；要自己核对就用第 4 节的测法 |
| 把 CML 负载换成通用多晶 | 恒摆幅偏置要求负载和带隙的 r_ref 同为高阻多晶，换了类型摆幅随工艺角漂 | 电阻类型是设计决定，不是版图决定 |
| 标准单元摆一排不放 tap | LU.2/LU.3 闩锁规则 100 处 | 标准单元按“行”摆，每 ≤ 15 µm 有一个 `tapvpwrvgnd_1` |

## 1. 规则数值（来自 `sky130A.tech`，单位 µm）

magic 里通孔/接触是**连同包边画的整块**（如 via1 块 ≥ 0.26 µm），导出 GDS 时自动生成真正的孔。下表“块”就是你要画的大小。

| 层 | 最小宽 | 最小间距 | 其他 |
|---|---:|---:|---|
| li（局部互连） | 0.17 | 0.17 | 最小面积 0.0561 µm² |
| licon（扩散/多晶接触） | 0.17 方块 | 0.17（扩散接触之间） | |
| mcon（li→m1） | 0.17 方块 | 0.19 | m1 四周包 ≥ 0.03，且某一方向 ≥ 0.06（met1.4/1.5） |
| met1 | 0.14 | 0.14 | 最小面积 0.083 µm² |

| met2 | 0.14 | 0.14 | 最小面积 0.0676 µm² |
| via2 块（m2→m3） | 0.28 | 0.12 | m2 在某一方向再多包 0.045 |

## 2. 套路

**接触排满。** 宽扩散的源漏不能只打一个接触：沿整个宽度按 0.17 方块、0.17 间距（中心距 0.34）排一列 licon，上面一条 li，再按 mcon 规则排一列 mcon 到 m1。8 µm 宽的管子每侧约 20 个接触。原因是接触电阻和电流分布，DRC 不会提醒你。

**折指。** 宽管子折成 nf 指，相邻指共用源漏，偶数指让两端都是源。W 总量不变，单元高度按 nf 缩小。参考网表写 `w=<总宽> nf=<指数>`；netgen 会合并并联器件。

**匹配对（差分对、电流镜）。** 同方向、同指宽；ABBA 或共质心交叉；两端加 dummy 栅；两侧走线镜像，长度相同。

**阱和接触。** N 阱内放 N+ 接触接电源，衬底放 P+ 接触接地，满足 15 µm 闩锁距离；模拟块外围一圈接触环。

**通孔叠。** m1→m3 = via1 块 + via2 块叠在一起，每层金属按上表包边。电流大或要降电阻时用阵列。

**MIM。** 上极板（capm）通过 via3 块接到 m4；m3 下极板包住 capm ≥ 0.14；不属于这个电容的 m3 离 capm ≥ 1.34，电源改走 m4/m5。

**标准单元行（如果某块用 `sky130_fd_sc_hd`）。** 行高 2.72 µm，单元的电源轨首尾对接；相邻行上下翻转共用电源轨；每 ≤ 15 µm 放一个 `tapvpwrvgnd_1`；空位用 decap 或 fill 单元补。

## 3. 流程（每步做完再往下）

1. 读参考网表和 [first_batch](first_batch.md) 里这块的约束，列出器件表和网络表（每个网络连哪些端子）。
2. 器件单元逐个生成，单独跑 DRC（只允许 `met1.6`）。
3. 画摆位草图（ASCII 即可），先满足对称/匹配，再考虑连线长度；敏感节点（相位节点、ctrl、z、vbias_q）最短。
4. 按网络逐条连线，每连 2–3 条网络跑一次 DRC，当场修，不要攒到最后。
5. 端口标签和 `port make` 的顺序 = 参考网表的引脚顺序。
6. 跑检查器，拿到三行原文。
7. 提取关键节点电容，和预算对比（`*_pex.spice`）。
8. 用 `verification/layout/plot_mag.py` 出一张图给所有者看。
9. 写 README，更新任务单状态表，停下等验收。

## 4. 交付前自检

- [ ] 参考网表和 Claude 给的版本逐行比对，除了 Claude 允许的改动没有别的差异
- [ ] 检查器：退出码 0，`DRC_TOTAL 0`、`LVS_MATCH True`、`LVS_PROPERTY_ERRORS False`
- [ ] 每个源漏、每个阱都有足够的接触；15 µm 闩锁距离满足
- [ ] 敏感节点寄生电容已列出，并与预算比较
- [ ] 删掉输出重新跑一遍生成脚本，结果相同
- [ ] 任何阻值/电容值如果要自己核对，用 ngspice 测实际器件，不用公式：

```
Rcheck
.lib "<model_library>" tt
V1 a 0 1
X1 a 0 0 sky130_fd_pr__res_high_po_1p41 l=16.82
.control
op
print 1/abs(i(v1))
.endc
.end
```
（`<model_library>` 用 `uv run python -c "from serdes_flow import project; print(project.model_library())"` 取；`.spiceinit` 里要有 `set ngbehavior=hsa`。）
