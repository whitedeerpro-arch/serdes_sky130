# PLL 版图独立审阅（2026-11-15）

**局部布局与电容 PEX 已有明确结果，PLL 整体性能尚未签核。÷8 的全量原生 RC 异常标成疑点待版图核查，该仿真分支暂停，不直接判实际版图失败。** 原生分布 RC 还存在电容重分配、几何属性分配和数值未完成项，当前也没有完整已布线 r6 PLL 宏。LDO、Bias 和 CP 按本轮范围不审阅，原理图偏置/CP 只作为测试边界。

| 对象 | 结论与入口 |
|---|---|
| [PFD](../../analog/pll/pfd/layout/review.md) | 布局保留；七个局部点功能通过；寄生后的复位脉宽明显增加，不能沿用原理图时序数字 |
| [VCO＋四路 buffer](../../analog/pll/vco/layout/review.md) | 撤除浮空 poly，保留独立候选；两个量程端点的耦合电容回灌仍包住目标；原生 RC 瞬态未完成 |

各模块报告和固定 JSON 是详细证据入口，不把不同版本、偏置、激励和初始化下的通过数拼成 PLL 通过。完整 RC、当前实际负载、MOS45/无源角、失配、相噪/抖动和最终闭环仍需按所属模块完成；这次未修改 Fable 的电路采用参数。
