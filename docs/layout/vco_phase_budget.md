# r6 VCO相位节点：寄生记账与走线规划

**当前r6每个相位节点已预留12fF走线电容，不是版图后还能再加12fF。** [r6环](../../analog/pll/vco/spice/vco_ring4_r6.spice)的八只`Cw*`由`cwire=12f`控制，覆盖环内、延迟级输出、变容/抽出buffer输入和阵列连接。5bit阵列共31个半单元；[单元模型](../../analog/pll/vco/spice/cap_bank_5b.spice)已含底板对地`Cbp`、并联MIM的边缘`Cfr`及开关AD/AS/PD/PS估算。[旧first_batch](first_batch.md)的15fF、0.5fF和码15属于旧设计，不能作为r6验收线。

## 原理图与PEX如何对账

| 项目 | r6原理图当前包含 | 提取后处理 |
|---|---|---|
| MOS本征、结与固定电阻/MIM器件 | PDK器件与明确几何；开关共享漏极面积为估算 | 使用提取器件属性，核对几何/指数量及PDK自身已含部分；不重复加同一寄生 |
| MIM底板与边缘 | 每半单元显式`Cbp/Cfr`估算 | 对应几何已被PEX覆盖时，用提取值替换估算；保留内部plate节点关系 |
| 相位节点连线与局部连接 | 每节点12fF共享allowance | 完整对应PEX中不再叠加该`Cw`；报告实际值相对预算的偏离 |
| 节点间/控制与供电耦合 | 当前集中模型只近似部分效应 | 保留耦合对象与网络，不能全部并成对地电容 |

完整ring/core提取回测时，原理图占位`cwire`应置0，并以实际提取连接和寄生替换对应模型。只换一个局部单元时，仅扣除这份PEX已覆盖的预算/估算，其余未提取部分继续保留；不能无条件清掉八个相位节点全部12fF。每次混合替换列清“保留、替换、尚未覆盖”的元件，先查是否漏算或双算，再解释频率差。

12fF是当前尺寸规划输入，不是已通过所有布局的上限保证。最终L4.77/WT25.2的约8.7%端点余量仍是近邻候选插值估计，[当前工作图](../design/pll_vco.md#r62026-11-12当前主线)与实际PEX要分别确认。器件/连接不匹配、内部浮空或端口断开时，不能先用电容预算将其判为可用。

## 历史单线标定可提供什么

以下为早期Magic几何提取记录：五条100µm长、0.4µm宽单线，间距5µm，`extract all; ext2spice cthresh 0`。脚本位置`analog/pll/loop_filter/layout/work/capcal.tcl`。本表未由本次r6修订重新独立复核，只用于布局初估。

| 层 | 100µm单线对衬底 | 每µm（宽0.4µm） |
|---|---:|---:|
| m1 | 9.18fF | 0.092fF/µm |
| m2 | 8.22fF | 0.082fF/µm |
| m3 | 8.64fF | 0.086fF/µm |
| m4 | 7.62fF | 0.076fF/µm |
| m5 | 7.97fF | 0.080fF/µm |

该稀疏结构记录的邻线耦合为0.03–0.07fF/100µm；不能外推到密集阵列、屏蔽、跨层、via或宽电源金属。按单根m2约0.082fF/µm，12fF约等于146µm孤立线，但实际所有局部连接共用该预算。旧60–80µm单层布线建议可以作为起步估算，不是r6合格门槛。

八相路径尽量保持相同连接拓扑和相近负载；等长不能独自证明电容或相位匹配。vctrl布线与屏蔽也要计入实际控制端导纳和相位节点耦合，旧0.2–0.7pF控制端数值不能直接给r6。

## 交付与回测边界

冻结当前参考、`.mag`、生成脚本、技术/模型身份后，在副本中独立DRC/LVS/端口/属性检查。每个相位节点报告对vss、vdd_q、vctrl、其他相位及内部plate的电容，保留耦合矩阵；列八节点最大值和散布，并说明与原理图哪些项相替换。旧“散布≤1fF”仅为早期对称性目标，r6仍须由相位/抖动和实际负载预算确认。

至少检查FS热/hh码0在窗口顶、SF冷/ll码31在窗口底的三供电范围；低增益角和其他全网格按机理扩展。两端覆盖2GHz之外，还要看摆幅、相间距、Kvco/控制端导纳与噪声；静态LVS或一条总电容不能替代这些检查。局部/最终版图统一依照[T3任务及参考](tasks.md)回测，不沿用旧4bit电容阵列或旧日志的通过结论。
