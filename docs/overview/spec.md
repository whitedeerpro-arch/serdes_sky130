## PVT 政策

**45 个环境条件全部必须满足功能和下列门槛。** 条件为 MOS 角 TT/SS/FF/SF/FS × 供电 1.65/1.80/1.95 V × 温度 −40/27/85 °C。

- 唯一允许缩水的指标是**高低温（−40/85 °C）下 4 Gb/s 的 BER**：名义 1e-12，高低温档放宽到 1e-9。
- 功能失败（丢分频、失锁、数据错误、时钟停振）不能降格为"低质量通过"。满足全部最低要求后，才按剩余裕量分级。
- 若以后要降额运行（例如低温降速），必须作为单独声明的速率/环境档位，不能隐含放宽。
- 1.95 V 而不是 1.98 V：SKY130 1.8 V MOS 公开模型的 VDS/VGS 有效上限为 1.95 V。器件端电压（尤其 CMOS 过冲）仍需逐项核对，见 [待解决问题](../status/open_issues.md)。
- 当前 PVT 只扫 MOS 角。电阻/电容工艺角、参考源误差、随机失配、噪声、版图寄生是单独的验证维度，不能用 MOS 角结果代替。

政策的机器可读版本在 [clocking_acceptance.toml](../../verification/corners/clocking_acceptance.toml)，环境矩阵在 [pvt_plan.toml](../../verification/corners/pvt_plan.toml)。

## 验收门槛

| 对象 | 门槛 | 当前用途 |
|---|---|---|
| TX 串化器输出节点 | 位中心有符号裕量 ≥ 75 mV；确定性边沿散布 ≤ 0.15 UI；训练/标记正确；无采样错误、多余或缺失跳变 | TX PVT 草案门槛，所有 45 条件适用 |
| TX 焊盘节点（输出级出口） | 与串化器节点相同：≥ 75 mV、≤ 0.15 UI、训练/标记正确、无错误或多余/缺失跳变 | 2026-11-08 起为门槛，所有 45 条件适用。负载为完整 TX 的代理外围：焊盘 200 fF、封装 0.3 Ω / 0.5 nH、AC 10 nF、RLC16、远端 50 Ω 到 0.9 V。信道之后的远端只作比较，链路门槛见 I-20 |
| CML 驱动目标 / 内部幅度复核 | 400 mVpp 差分目标；原内部上界适用性复核中 | TX 输出级远端（近无损信道）约400mVpp。原内部≤400的筛查保留历史记录，当前不只凭越过该数值淘汰候选，也未采用新的上界。逐节点以换向、眼图、共模/堆叠余量、器件应力与噪声确定可用范围，见[幅度依据](../design/cml_swing_target.md) |
| 内部 CML 节点摆幅 | 硬下限 150 mVpp，设计目标 ≥ 200 mVpp | 要求是跨 PVT 能让下一级完整翻转；不足时用 buffer 恢复，其功耗和附加抖动计入 P4 预算。VCO 节点除外：其摆幅由相噪预算决定（摆幅减半相噪约差 6 dB） |
| CML 时钟功能筛查 | 差分 ≥ 150 mVpp；周期误差 < 1%；边沿数正确 | 瞬态功能筛查 |
| CMOS 时钟功能筛查 | 低 < 0.2 VDD，高 > 0.8 VDD；完整周期占空比 45–55% | 时钟接收器/分频器 |
| PLL 锁定（工程判据） | 32 参考周期窗口、步进 8 周期；平均频差 ≤ 100 ppm；展开相位变化 ≤ 20 ps；在记录末尾持续 ≥ 320 ns | 见 [测量约定](../verification/measurement_conventions.md) |

各量的精确定义（裕量、散布、训练定相、眼图显示）见 [测量约定](../verification/measurement_conventions.md)。

2026-11-06 核对：共模公式修正了单端/差分的二倍关系，没有改变 400 mVpp 上界。内部实测超过该上界，功能窗口通过不能代替幅度符合性；2026-11-08已整理[完整TX逐节点摆幅](../design/tx_cml_amplitude.md)，见 [I-17](../status/open_issues.md) 和[设计评估](../history/design_coupling_review_20261106.md)。

**2026-11-11当前解释：** 上一段记录当时的验收政策；内部400mV上界的物理依据现进入复核。原始波形、仿真前约束及历史评分不改写。新的尺寸比较把“偏离400mV目标”与实际眼图、余量或应力失败分开；尚无可替代的通用上界，I-17继续保留。

## 抖动与相位噪声预算

当前 r6/PTAT 与 PLL v4 的五点模型见[VCO 与 PLL 噪声报告](../design/pll_vco_r6_perf.md)。系统预算按采用的反馈、供电和链路边界在 I-TOP-05 收口。下方保留 r5 的门槛推导与当时的模型读数。

**结论（PLL r5 候选，2026-11-05）：环路取 k = 4（Icp 200 µA、Ci 10 pF、Cf 0.5 pF）时，BER 1e-12 下预算有约 0.41 UI 余量，高低温不需要放宽 BER。** 这是模型结果，闭环和 45 × 电阻角还没验证。

| 项 | UI | 来源 |
|---|---:|---|
| 无噪声采样窗口（最差：SS / FS 1.65 V 85 °C，R hh） | 0.81 | `link_pvt`，码步 1/16 UI |
| 随机抖动 14.07σ，CDR 后（最差：SF 1.65 V 85 °C，R hh，5.74 ps） | 0.323 | ISF + 线性 PLL + CDR 模型 |
| 时钟路径附加抖动（按 1.5 ps 平方和并入） | +0.011 | 手算，未仿真 |
| 电源纹波 | 0.05 | 门槛（下文） |
| 参考杂散 | ≤ 0.01 | 手算 |
| **余量** | **0.41** | |

r5 候选七个工况的噪声、CDR 和电源灵敏度数据见 [VCO](../design/pll_vco.md#相位噪声r5-候选)。TX、RX 按两个独立 PLL、同一工艺角算。

**门槛（PLL 收口时在 45 × 电阻角上查）：**

| 量 | 门槛 | 推导 | 七工况现状 |
|---|---:|---|---:|
| 随机抖动 14.07σ（CDR 后） | ≤ 0.50 UI | 0.81 − 0.05 − 0.01，再留 0.25 UI 给未建模项（边沿噪声假设、版图、失配） | 0.255–0.323 |
| VCO L(1 MHz) | ≤ −80 dBc/Hz | k = 4 下按比例估算，−80 dBc/Hz 约对应 0.44 UI | −84.9 … −90.2 |
| 电源到频率 \|K\|（20 MHz） | ≤ 150 MHz/V | k = 4 下对应 0.05 UI 峰值时约 17 mV 正弦 | 现行 k = 4 环路任何分接都不满足：12/6 最差 160（FS 1.8 V 85 °C hh），23/36 全 45 条件 58–153、两点超出（2026-11-10，见 [PLL 电源抑制](../design/pll_loop.md#电源抑制第7步2026-11-10)） |

VDD 实际纹波还没有估算（电源网络未建模，I-29），所以电源这一行是容限，不是已满足的结论。

**方法和假设：**

- VCO：ISF 法，噪声源为负载 R、输入管、尾管的热噪声和闪烁噪声，见 [验证方法](../verification/methods.md#相位噪声)。
- PLL：线性模型，参考 + PFD + 分频器合成带内底噪 −125 dBc/Hz（**假设**，折合每参考沿约 0.71 ps；降到 −113 dBc/Hz 时 SF 热角 k = 4 只从 2.75 升到 3.19 ps）；CP 占空比 0.11（**旧 PFD 记录**）。
- CDR：KP 1/8、延迟 4 个控制周期、边沿噪声 9 ps（**估计值**），模型未和 RTL 对过。
- 均约定：载波 2 GHz，单边 dBc/Hz，积分 10 kHz–1 GHz。无噪声瞬态的边沿散布不能当作随机抖动。

## 已确认的取舍（2026-10-31）

- **BER**：名义 1e-12（无 ECC）是 4 Gb/s 常见规格，约每 250 s 一个错位，作为抖动预算的锚点。ECC 是后备，不进基线。
- **400 mVpp（历史取舍，内部上界自2026-11-11复核）**：当时作为上界和驱动目标，不是内部节点下限。现有 r3 分频 tap 最低约227mVpp，满足内部目标；VCO节点摆幅由相噪预算判定：r3在SF 1.65V 85°C、R hh只有237mVpp，不够；r5候选七工况389–493mVpp。
