# 架构决定（2026-11-12 起）

本文件保留既有技术决定与当时的 Claude 署名；当前技术主线以 Fable 为准，Codex 承接工作组织、基础设施、局部实现与复核。每条写明决定、原因和验收口径；模块维护详细结论，项目级采用与验证汇总在 [current.md](current.md)。

## 结论

1. **拓扑不换。** CML 环振（多晶电阻负载＋MIM 阵列＋变容管）、16:1 CML 选择树、半速四相采样＋数字 PI-CDR 都保留。r3→r5 已把节点损耗和相噪摸清，换拓扑要重做全部噪声表征，收益不抵风险。
2. **版图寄生进原理图。** 每个高速节点在原理图里带显式寄生余量（参数，如 VCO 的 `cwire`），量程和时序余量都在带余量的网表上验证；提取网表实例化时把余量参数置 0。此前“原理图刚好够、版图预算 ≤ 8 fF”的做法作废：那个预算版图做不到（见第 3 条）。
3. **VCO 出 r6**（[VCO](../design/pll_vco.md#r62026-11-12当前主线)，已定版）：阵列 5 bit（31 个 2.0 × 2.0 µm 半单元，单元里带下极板、边缘、漏极结的寄生），每个相位节点 12 fF 连线余量，尾管 W 25.2。量程两端候选实测约 ±8%（目标 ≥ 约 6%：失配 3σ 约 3% ＋ 连线估计 ±6 fF 的不确定度），窗口/LSB 预计 ≥ 2。r5/4 bit 及其码表、粗码窗口结论只作历史。
4. **CML 负载用成对的长电阻，不用单只短电阻。** 高阻多晶的头部电阻不跟工艺角走：约 337 Ω 时单只短的 hh/ll ±20.7%，两只长的并联 ±14.7%。r6 负载在网表里直接写成两只 `res_high_po_2p85 l=4.77`，原理图器件 = 版图器件，不再靠脚本映射。TX 的短 CML 负载同理。
5. **设计余量的口径**：量程类余量 = 失配 3σ ＋ 未提取寄生的不确定度，在 45 条件 × tt/hh/ll 定宽电阻卡上取最差。仿真“刚好通过”不算通过。
6. **PFD 用标准单元 `pll_pfd_sc_dly`**；复位环路 ≥ 1.4 × `dfrtp_1` removal 约束是这类结构的设计规则。
7. **PLL 时钟前端精简（`clock_frontend_r6q`）**：四个全速 CMOS 接收器无消费者，删除；三条 dummy 预分频支路（11.5–17 mA）改成只含输入级的轻 dummy（每条约 0.34 mA）。VCO 相位节点由 buffer 隔离，dummy 只影响 buffer 输出负载；估算相位影响 < 0.2 ps（VCO 节点）。对比台 `analog/pll/top/tb/frontend_r6` 验证频率、八相间隔和电流后采用。
8. **验证顺序**（2026-11-13 修订）：r6 两端 → r6 全图（已完成）→ ÷8 在 r6 量程内的上限 → r6 原生闭环 → **锁定的 r6 PLL 驱动完整 TX、动态数据，同一 deck** → 扩角、dummy 配重、参考输入 → 相噪/失配/抖动预算按 r6 重算。把“PLL＋TX 联合”提前到闭环之后立刻做：各模块都已在自己的边界上通过，项目最大的未知是接起来以后。RX 维持现状，不在这一轮。
9. **名额**：全机最多 4 个 ngspice，由集成者按主线分配；Codex 开跑先在[协作页](../work_packages/collaboration.md)登记并协调。没有永久2+2分割，登记与实时进程都须核对；历史借用记录不自动成为当前配额。
10. **当前数字只有一个出处：[current.md](current.md)。** README、development_map、prelayout_plan与工作台只链接项目级验证汇总，不复述数字；设计文档保留原理、取舍、按修订标识的详细结论和历史证据。`config/*_working_revision.toml` 保留机器参数、数据身份及兼容字段，不新增长篇汇总结论。每条证据必须写明实际驱动/边界（理想源、录波回放、开环原生、闭环原生），读数以它为准。原因：同一结论散在五六处，各处措辞不同，已经让人把“开环原生静态”和“没用过实际时钟”混为一谈。

文档职责与任务执行方式见[文档导航](../README.md)和[工作流](workflow.md)；近期顺序在[执行计划](prelayout_plan.md)，不另增一份技术主线。

## 为什么 r5 不能直接进版图

- 1/f 对节点电容严格成直线；慢端（FS 1.65 V 85 °C hh，码 0，窗口顶 1.21 V）等效节点电容 150 fF，附加 0/8/16 fF 时 2.108/2.001/1.906 GHz：**8 fF 用完全部余量**。
- 现实版图每节点约 17–20 fF：阵列断开残余（单元画到最紧每个约 +0.33 fF，×15）、延迟级输出走线约 4.4 fF、环内与阵列连线约 8 fF。带这些寄生的 r5 在窗口顶只有 1.902 GHz。
- 负载 400 → 362 Ω、尾管 20 → 22.1 µm（等摆幅）：2.109 GHz，摆幅不变。频率 ∝ R^−1.03。
- 仿真成本：VCO 单点由 24 ns / 2 ps 改为 14 ns / 4 ps（7 ns 起已稳定，步长误差 −0.017%），每点约 90 s → 20 s，全图约 14 h → 3–4 h。

结果：`results/analog/pll/vco/parasitic_ends/20261111T195250Z`、`20261112T044311Z`（[测试台](../../analog/pll/vco/tb/tuning/parasitic_ends.py)）。
