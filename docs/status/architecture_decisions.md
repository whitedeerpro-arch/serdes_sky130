# 架构决定

当前技术主线以 Fable 为准；Codex 承接工作组织、基础设施、局部实现与复核。每条写明决定、原因和验收口径；模块设计文档维护详细结论，项目级采用与验证汇总统一在 [current.md](current.md)。

## 1. 2026-11-26 收敛架构决定

1. **主推双速 4/5 Gb/s LC-PLL + CMOS/SST（Plan-C），并保留 4.0 Gb/s 无电感环振基线对照。**
   - **决定**：5.0 Gb/s 主线采用 5 GHz 八边形 LC-VCO + 正交 ÷2（`lc_vco_5g_oct_pdk`）、双速 A/B 分频 ÷8/÷10（`div_ab_5g_v2_pdk`）、5G I/Q 时钟组宏、HV18 Kelvin LDO（`v2_cur_kelvin_pdk`）、TX SST `v5_pdk`、RX CMOS `rx_top_5g_pdk`（W3 紧凑峰化 CTLE + `4→8` I/Q PI v3 + 5G Double-Tail 采样器）及端口协同 32-bit 降频双速数字顶层 `serdes_digital_top_v4`（`v4p1`）。同时保持 4G `v1.0` / `full_v8`（2 GHz 四级环振 `r6` + PTAT + SAFF-TSPC ÷8 + TX v4.3 + RX v2.2 + 数字 v3.1/v3.2）作为无电感参照。
   - **原因**：LC-VCO 以低相噪与单码跨全温 `125 °C` 连续锁相解决 5 Gb/s 抖动瓶颈；32-bit `160 MHz` 主机域彻底消除 16-bit `250/312.5 MHz` 在 SKY130A `1.65 V −40 °C` 下的时序赤字；CMOS/SST TX/RX 在功耗与面积上显著优于早期全 CML 路线。
   - **验收口径**：各宏独立通过 Magic DRC=0、Netgen LVS=MATCH、真 CPEX/RCX（`SPARSE 1.3`，零 `klu`/零 `cshunt`）与局部失配 MC；片顶通过 Plan-C 装配与层级提取签核，流片前按 [执行计划](prelayout_plan.md) 补齐 Padring/LVS/RCX/IR-EM 与整机冷启动联调。

2. **版图寄生与失配前置进设计与签核。**
   - **决定**：所有高速与敏感模拟节点在原理图阶段即带显式寄生余量建模，并尽早完成 PDK 版图与 Magic CPEX/RCX 闭环；量程类余量 = 失配 `3σ` + 未提取寄生不确定度，在 45 PVT × 无源工艺角取最差。仿真“刚好通过”不算通过。
   - **原因**：4G `r5→r6` VCO 与 5G `slicer / TX / PI / div_ab` 的多轮实测反复证明，SKY130A 下的布线寄生与冷角 `|Vthp|` 失配会直接吃掉标称裕量，只有真 CPEX/RCX 与 `_mm` MC 能可靠暴露实硅风险。

3. **片级物理装配采用 Plan-C 端口协同、双护环隔离与预期连接表门控。**
   - **决定**：5G 全片采用 `936 × 650 µm` Plan-C 紧凑布局：LC-VCO `R90` 西置并留电感护环，TX 正南 `TX_PAD_P/N` ⊥ RX 正东 `RX_IN_P/N` 90° 正交出线，双 P+ 衬底隔离沟隔开安静岛与开关区，8 组紧缩 Direct/Damped/HV33 去耦瓦片分域配置；数字顶层 `v4p1` 与 `rx_top_5g` 做 33-bit 零交叉端口协同。后续片顶提取门控统一改由预期连接表驱动（同步核查端点存在、完整网组连通、域隔离与显式 NC），杜绝缺失端点被 `must_differ` 放过。
   - **原因**：2026-11-26 独立物理复核（[片级报告第 10 节](../layout/chip_floorplan_20261123.md#10-实装金属与分析缺口复核2026-11-26)）表明，显式全网连接表是拦截 `icml` 短接与悬空控制端口的最可靠机制。

## 2. 持续生效的电路、验证与协作基础规则

4. **成对长高阻多晶电阻原则。** 高阻多晶负载优先用成对长电阻并联替代单只短电阻，降低头部电阻占比与 `hh/ll` 工艺角漂移，且原理图器件 = 版图器件，不依赖后处理脚本映射。
5. **标准单元 PFD 复位约束。** `pll_pfd_sc_dly` 复位环路满足 `≥ 1.4 × dfrtp_1` removal 约束作为同类结构的硬设计规则。
6. **仿真名额管理。** 全机最多并发 4 个 `ngspice`，由集成者按主线统一分配；开跑前同时核对[协作页](../work_packages/collaboration.md)登记与实时进程，不保留旧的固定 2+2 分割。
7. **当前数字唯一出处：[current.md](current.md)。** README、模块地图、执行计划与工作台只链接项目级验证汇总，不重复抄写数字；模块设计文档保留详细分析与历史边界；每条验证结果必须写明实际驱动/寄生/负载边界（理想源、录波回放、真 CPEX/RCX、闭环带载等）。
