# 版图前：设计恰当性与下一步验证

**现有证据支持保留 SerDes 的主要架构，优先闭合模块接口和局部余量。** 当前尚有明确规格问题，也有当前修订缺测、旧修订证据和数值收敛问题，不能归为同一种“还没集成”。PLL 已有完整电路与启动顶层；新供电和其他改进继续作为局部迭代验证，再做必要的联合确认。

本页是当前推进判断。持续目标与执行边界见[版图前完成目标](serdes_completion_goal.md)，本版按[半定型决定](next_iteration.md)推进。[11-06评估](../history/design_coupling_review_20261106.md)保留当时证据，旧CP、分频和TX候选结论不能直接当作当前状态。具体参数以各 `config/*_working_revision.toml` 为准，稳定编号见[问题表](open_issues.md)。

## 本轮实际推进

LDO r4电路与证据已提交`96fb28b`：DC1215点、AC255点、实际无源/校准/启动和独立噪声谱。额外100pF已补5MOS×5RC×17边界/名义条件共425条DC/AC，最差PM65.07°、20MHz抑制38.44dB；原同R角电压码固定不变。见[逐点数据](../data/ldo_r4_pin_cap.json)。实际引脚、ESR、电容区间和真实PLL动态仍未提升为完成。

RX FF冷角已核对当前W40闭包：七个原始文本差异均由PDK电阻映射解释，映射后与当前源码一致。原FF/hh 1.95V −40°C、固定名义C2回放下，普通OP返回OPtran候选；同FF的7943电压软初猜使独立Newton在禁用全部回退下得到工作点。四个主要偏置与FF单元DC一致；1ns健康后完成44.75ns字流，7字/112数据位/55确定边沿零错，16路单独映射均唯一。原FF的W80超时保留，不将新工作点或冒烟当成真实启动/整链资格。

## 判断和执行约束

本轮结论来自现行文档、配置、网表及所引结果；不代表已经重跑所有历史波形。MOS45与RC库段、理想/真实参考、输入回放和实际扇出分别记录；没有门槛的物理量为ungraded。MC/PVT、无噪声字流/BER、OP/真实启动、局部AC/振荡动态均保持各自资格。

仿真最多使用Codex两个名额，全机四个；长活动逐条件续跑。已有明确局部失败或中等难度结构修补时，先用约束/粗模型筛选并同时比较替代结构，再决定电路实验；不以扩大长全链扫描代替定位。
