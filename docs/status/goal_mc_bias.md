## 已定的选择

| 项 | 决定 | 理由 |
|---|---|---|
| a. 参考电流定义 | 恒摆幅：I = m·Vbg / R，R 与 CML 负载同类单元（high_po） | 摆幅与电阻角（±12.5 %）、电阻温度系数无关；CP 同样定义时 Icp·R_lf 不变（[偏置](../design/bias.md#架构方案2026-11-03)） |
| b. 修调 | 带隙带修调（约 4 bit），MC 定修调范围 | 失调到 Vbg 的增益 12–17，靠面积压失调代价平方增长 |
| c. PNP 比例 N | 先 8；MC 显示 vbg 随机误差以 PMOS 源失配为主，N = 24 只降放大器那一项，修调覆盖 | — |
| d. 电阻角 | 现在先用"恒摆幅模拟"（负载 × (1 ± 12.5 %)、参考电流 × (1 ∓ 12.5 %)）检查 CML 关键路径，接入真实偏置后再完整重验 | 现有网表的负载是理想电阻，库的 ll/hh 段对它们无效 |

## 阶段

1. **MC 方法**（文档 + 工具）：三层（器件参数 → 模块指标 → 系统判据）；全局偏差用工艺角、局部失配用 `*_mm` MC；串联判据（每个实例都必须过）与传播判据（平方和）；样本数与容差区间；瞬态类指标的 MC（`serdes_flow.mc` 支持 tran + meas）。
2. **现有设计的失配分析**：采样器输入失调（4 路，占位裕量 75 mV 的多少）、时钟相位 / 占空比误差（D/E 间距）、PI 单调性与 INL（≤ 0.02 UI）、CTLE 失调；先 TT，再在最差 PVT 点复核。
3. **偏置 / 带隙**：电阻角检查（d）；带隙核心 + 误差放大器（约束 + 粗模型 → 求解 → TT 仿真 → 校准）、V→I、B1 / B2 缓冲、启动、修调；PVT（MOS × 电阻角）、MC（修调范围）、启动、PSRR / 噪声（记录）。拓扑选择单列为 sizing 之前的一层。

## 剩余

- 带隙修调实现（R2 分段开关，5 bit）与修调后的 PVT / MC 复核；vcm 随之进入 ±50 mV。
- 采样器失调校准（结构 + 范围）；与 CTLE 失调一起回到裕量预算。
- 电阻角：用真实偏置 + `rcorner.to_pdk` 重验 CML 关键路径（含 SS 85 °C 栅极时钟 280 mVpp 的处理）。
- PSRR 改进；LF 预充缓冲 B2；偏置分配与去耦。
