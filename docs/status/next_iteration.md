# 下一版与延后候选

本页只存放尚未进入当前交付范围的方向，不承担现行架构决定或当前供电容限发布。当前修订见[current.md](current.md)，主线顺序见[执行计划](prelayout_plan.md)。原2026-11-10“半定型、4bit、供电已定”的表述及当时数值保留在[历史快照](../history/next_iteration_snapshot_20261110.md)；其后r6及供电路径复核按[架构决定](architecture_decisions.md)和当前证据承接。

| 候选 | 需要先量化什么 | 进入本版的条件 |
|---|---|---|
| VCO或VCO＋CP/LF改为1.5V低纹波域 | 最低输入压差、功耗、量程/码表、CP窗口、LF分接与监测门限；见[供电变体规划](../design/pll_supply_variants.md) | 现主线边界无法满足且替代方案有可复核收益，由Fable/所有者决定 |
| 缩窄模拟核心电源范围 | 电压范围造成的面积/功耗/尾管余量和验证成本；区分宿主纹波进入路径 | 明确新范围、供电实现和回归成本，不能直接减少现行MOS45义务 |
| 更强信道、FFE或其他链路扩展 | 目标信道/链路门槛、C3与C2的差异、代价与收益；见[信道](../design/channel_model.md) | 先确认范围与规格；现行I-20链路门槛缺口仍在本项目保留 |

局部反例、器件不可实现或中等难度修补仍按工作流比较替代结构，不因列在“下一版”就搁置现行功能失败。
