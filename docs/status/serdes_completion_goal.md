# SerDes 项目完成目标

完成 SKY130、1.8 V、4 Gb/s SerDes 的可实现电路设计、必要优化与可复核验证，并按明确的模块边界推进物理实现。项目关闭以以下交付条件为准；完成一次文档整理、一个单元或一次局部里程碑不代表 SerDes 完成。

## 本版范围与约束

采用范围以[当前状态](current.md)、[工作修订](../overview/revisions.md)和 [Fable 的架构决定](architecture_decisions.md)为准。当前 VCO 为 r6/5 bit，旧 r5/4 bit 的码表、工作区与噪声结果仅按历史边界保留；未改动 CP/分频等单元的结果按输入/负载继续继承。供电配置在初始化静态选择，新的供电架构候选见[下一版](next_iteration.md)。

规格以[规格文档](../overview/spec.md)为准：MOS45条件全部满足功能与适用门槛，按机理补无源角、真实偏置/负载、失配、噪声和寄生；唯一允许缩水的是高低温4 Gb/s BER。PPA在功能、PVT、噪声之后。遇到中等难度的局部修补同时准备替代结构的模型对照，由Fable判断是否采用，不自建冲突主线。

## 交付与关闭条件

| 交付 | 完成标准 | 证据位置 |
|---|---|---|
| 采用的实现 | SPICE/RTL、端口、配置与模块说明一致；候选和历史修订可区分 | 工作修订、模块设计文档与版本标签 |
| 功能与时序 | 当前实现按适用场景通过MOS45；串化器/焊盘、位映射、分频/锁定和数据域接口按各自判据成立 | current.md链接到完整运行/指标；失败、数值未完成与未测单列 |
| 原生接口与启动 | 锁定PLL→动态TX、RX原生锚点、ready/粗搜/捕获、实际失配校准、生产参数CDR、训练/重训和宿主CDC有可复核实现与验证 | 模块/接口实验、RTL/时序检查；模型与物理校准对应 |
| 噪声与统计 | 当前尺寸、码、供电与负载下的相噪、随机/确定性抖动、供电及共享参考路径、失配与预算一致 | 噪声/统计报告及规格预算；PDK盲区显式保留 |
| 物理可实现性 | 器件族、定宽R/MIM、指宽/体端、寄生、敏感节点/匹配、应力与电流容量有依据 | layout模块文档与提取回测；DRC/LVS仅证明对应检查 |
| 设计收束 | 受影响角点与接口回归完成，优化PPA，采用网表与交付原理图一致，剩余问题有关闭或明确范围处置 | 当前状态、问题编号、版本与结果索引 |

版图前电路交付与版图宏交付分别验收。当前具体物理工作范围见[PLL r6版图](../layout/pll_r6.md)；该模拟核以外的LDO/全局偏置/控制接口不能因暂作外部边界而从系统目标删除。全SerDes PEX签核须有全系统对应提取与验证，不能由叶单元迁移数或局部回灌推断完成。
