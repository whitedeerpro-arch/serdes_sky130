# SerDes 版图前完成目标

持续目标：完成当前 SKY130、4 Gb/s SerDes 的版图前设计、必要调整与可复核验证。局部里程碑不结束整个目标；完成条件沿用[版图前计划](prelayout_plan.md)，MOS45功能/规格、噪声/抖动优先于PPA。仅高低温4Gb/s BER按既定政策处理。

## 本版范围

按[半定型决定](next_iteration.md)保持主要架构、4bit VCO和k=4环路。1.8V直供配置使用合格外部电源，较差供电用3.3V HV18 r4＋尾偏置滤波；初始化静态选择。VCO1.5V留下一版，本版不主动扩成架构重做。

后续以边界补全、参数定型、调校和优化为主。TX内部摆幅/再生/时序冲突、物理guard延迟等若确实不能由参数解决，仍需局部结构对照；保持现有功能门槛，不承诺“只改参数即可”。ready、校准、码驱动/门限供电域和数据接口属于待完成的功能。

## 分阶段结果

| 阶段 | 可复核的完成条件 |
|---|---|
| 当前修订与缺测 | 每模块的源码、配置、工作台和明确数据身份一致；分开历史证据、当前结果、功能失败与数值未完成。先完成RX当前W40冷角等明确缺口 |
| 局部设计闭合 | TX幅度/再生/相对时序及物理控制；PLL工作区、实际门限/停止规则/切码；RX读出、生产参数CDR与实际校准。结构比较先模型、局部校准后再扩网格 |
| 供电与模块接口 | quiet/host域、真实源负载、参考与偏置ready、原生时钟/扇出和必要数据域接口。复用已有PLL完整顶层，不把每项局部迭代变成整机长仿真 |
| 噪声与统计 | 当前码/负载/供电下的相噪、随机/确定性抖动及局部失配与预算对应；PVT和确定性失调压力不冒充MC；PDK缺项显式保留，不能宣称未建模量已通过 |
| 收尾 | 受影响的45个MOS条件及机理相关无源/源负载回归；合理的启动、捕获、校准和位映射证据；PPA和版图约束整理，采用网表与原理图/文档一致 |

长时系统行为优先用模型，并由实际模块/接口测试校准；必要原生长仿真只验证具体未确定的问题。整个SerDes全部从零启动的长晶体管仿真不是每个步骤的前置条件。

## 协作与成本

Claude与Codex按实际进展协作，没有固定的模块禁区。改前读[协作记录](../work_packages/collaboration.md)，在同一文件上交叉编辑时先说明具体范围；不覆盖对方工作区或代为提交未审查改动。每次只提交自己已核对的路径/段落。

全机ngspice≤4，通常各最多2个；借用空闲名额先登记。当前Claude跑quiet PLL压力角的hv/ext原生闭环；Codex已完成RX FF W40短窗，推进TX非再生时钟级的局部尺寸校准。每项均按条件续跑、检查完整终点和输入身份。

[Xe2局部尺寸卡](../design/tx_buffer_local.md)已在TT/FS实际加载切片上复现基线并测单轴/联合扰动，联合点降至338/316mVpp、模型残差<0.3mV；后一级仍473/414mVpp。[五级统一减幅](../design/tx_buffer_cascade.md)在FS出现69.75mV/0.212UI的局部规格失败，不采用；下一轮保留更多增益再回完整TX。

TT原生quiet PLL两条1.5µs结果各约2.1h、约37.8万保存点。离线前缀复用原分析器，HV的600ns尚未满足末端锁定判据，800ns与1500ns的捕获/频率/纹波接近；只能作为这两条TT预充边界的短筛依据，不能推广所有压力角或直接预测实际耗时。[成本与窗口数据](../data/native_pll_cost.json)、[采集器](../../verification/analysis/native_pll_cost.py)。日志没有分阶段计时，OP与瞬态耗时比例尚未知。
