# 测量约定

> 时域结果统一用 UI 作时间轴：4 Gb/s 下 1 UI = 250 ps（2 GHz 时钟周期 = 2 UI，16 位字 = 16 UI）；5 Gb/s 演进路线下 1 UI = 200 ps（2.5 GHz 半速率时钟周期 = 2 UI，32 位字 = 32 UI）。原始数据仍以 SI 单位保存。

## 数据眼图与裕量

**定相只用训练段。** 每个观察节点用训练段确定一个固定的分数 UI 延迟，再用唯一标记消除整数 UI 歧义；之后整段负载使用这个固定延迟和固定 250 ps UI，**负载数据不参与相位或 UI 拟合**，不逐位、逐字调相。

| 测试族 | 训练 | 负载 |
|---|---|---|
| TX PVT（v0.1 基线） | 32 bit 交替 + 32 bit 唯一标记 | 128 bit（独立输出级 256 bit） |
| TX r2 | 前 64 bit | 128 bit；长记录 1024 bit |
| 早期串化器/时钟分发 | 0xAAAA × 2 测延迟，0xD3A5、0x6C9E 定整数位 | 64 字 |

| 指标 | 定义 |
|---|---|
| 位中心有符号裕量 | 每个负载位在位中心采样，`电压 × 期望符号`，取最小值；门限为差分 0 V |
| 采样眼高 | 所有位中心中最小高电平减最大低电平 |
| 确定性边沿散布 | 匹配到的数据跳变相对固定时基的时间残差峰峰值（UI）；含码型相关延迟，不是随机抖动 |
| 多余 / 缺失跳变 | 匹配窗口半宽 0.45 UI 内找不到预期跳变计为缺失，额外过零计为多余 |
| 功能（functional） | 训练与标记正确，且无采样错误、多余或缺失跳变 |
| 串化器草案门槛 | 功能 + 最小裕量 ≥ 75 mV + 散布 ≤ 0.15 UI |
| 总峰峰值 | 窗口内电压极值，含过冲与长连码；不能代替采样裕量 |

## 2 UI 眼图显示

默认 2 UI 眼图显示约定：总宽 2 UI，向右平移 0.5 UI，中央为一个完整（偶数位）眼，左右各半个（奇数位）眼，在边界回绕处断线。只改变显示，不改变 UI、训练延迟、采样点和指标。

## 时钟测量

| 指标 | 定义 |
|---|---|
| 频率 | 稳态窗口内同极性差分过零的平均周期；未起振或周期不足时不可用 |
| 分频正确性 | 以实测 VCO 周期为坐标，数连续输出上升沿之间的 VCO 周期数 |
| CML 时钟功能筛查 | 差分 ≥ 150 mVpp、边沿数正确、周期误差 < 输出周期 1%、至少三个周期 |
| CMOS 时钟功能筛查 | 两路都达到 < 0.2 VDD / > 0.8 VDD；完整周期占空比 45–55%；最小高/低脉宽 > 0.3 周期 |
| 相位 | 以加载后 250 MHz 下降沿为 0，单位 UI；比较时保留分频启动状态 |
| 尾管余量 | 时间平均 VDS − VDSAT（BSIM 工作点），同时记录最小值与低于 VDSAT 的采样比例 |

## PLL

**锁定工程判据**（[pll_lock_screen.toml](../../verification/contracts/pll_lock_screen.toml)）：32 个参考周期窗口、步进 8 周期；平均频差 ≤ 100 ppm、展开相位变化 ≤ 20 ps；在记录末尾持续至少 320 ns。报告的时间是最终持续合格区间的起点，还需再观察 320 ns 才能确认。相位均值可以非零。窗口必须完全落在保持区内（早期判定把跨入保持区的窗口计入，造成过保守误判，已修正）。

**PFD/CP 电荷**：在稳态后半窗口对完整参考周期积分 `Q = ∫Iout dt`，含开关尖峰与关断电流；UP 为正。有效电荷增益用 ±200 ps 两端割线。

**Kvco**：注明 Hz/V、粗码、计算点和区间；三点分段线性模型只在实测控制电压范围内有效，闭环轨迹不得越出该范围。

## RX

- 实时联调中真实 CMOS 电压 ≤ 0.3 VDD 判 0、≥ 0.7 VDD 判 1（1.8 V 时 0.54/1.26 V），中间记为 unknown；这是仿真解释规则，不是硬件比较器。
- 读出在真实时钟边沿后固定延迟（pair 对齐为 350 ps）进行。
- CDR 首次质量标志是状态定义下的时间，不是噪声条件下的捕获时间。

## 功耗

按实际时间积分的平均值，注明窗口与电源轨。外部理想参考支路单独列出，共享参考不重复计入。失效状态下的低功耗不能作为同功能的节能对比。
