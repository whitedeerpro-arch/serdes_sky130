# PLL 验证工具复核（2026-11-17）

本批接收原生 r6 测量/续跑、相量提取和局部噪声副本工具，不改变 DUT 或工作修订采用参数，也不扩大历史波形的资格。

`clock.feedback_lock` 是原生台的 16 周期均频、末 60 沿诊断，拒绝重复/跳过反馈边沿及不足的窗口；`pll_lock.screen` 是 32 周期窗口、步进 8 周期、持续至少 320 ns 的工程评分。二者都新增记录末尾参考停止的拒绝检查，不能用较早的一段好记录证明声明终点仍锁定。它们不能替代抖动/噪声验证。

`native_r6/campaign.py` 保存明确选码表、供电修调、项目依赖、准备 deck、外部库及源码哈希；续跑检查身份、日志与实际终点。每工况先独立 1 ns 冒烟，结果按 attempt 和 analysis 追加。`run.py` 的工况路径组合错误修复，分频 tap 的确定性初始化扰动在 bench 中显式保留；这种启动辅助不计为真实从零上电资格。

`spectral.tone` 用时间权重拟合 DC、线性趋势与正余弦，避免自适应时间网格偏置。`noise_models.varactor_rg` 仅生成独立模型副本，在行为电阻上启用 `noisy=1`；电气表达式和原 PDK 不改。副本与实际物理噪声的适用范围仍需由所属实验定义。

旧 4-bit ISF pilot 还有一项身份修正：共享 ring 的默认 bank 已改为 MIM 2.52×2.68 µm、开关 W2.68，而该 pilot 的计划仍写 W2.5。新准备的 deck 明确覆盖为该历史实验的 MIM 2.35×2.5 µm、W2.5；旧冻结 campaign 不重写或自动续接。单元测试检查实例覆盖，不能靠匹配共享文件里的旧数字判断实验尺寸。

本次通过合成边沿、缺失终点、输入篡改/截断、相量和模型副本等测试复核工具行为；未启动原生闭环或 ISF 长仿真。工程锁定的历史数字仍由固定来源及独立评分报告决定。
