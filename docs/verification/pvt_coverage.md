# PVT 覆盖

> 45条件＝MOS角×VDD×温度；135＝再乘tt/hh/ll无源RC库段。覆盖必须绑定变体、真实/理想偏置、负载、测量项目和动态场景，不能把不同批次的网格相加为整机通过。逐块版本、失配和下一步见[设计框图与开发状态](../overview/development_map.md)，关键汇总身份与计数见[核对快照](../data/design_status_evidence.json)。

## 跨模块仍未闭合的维度

- 真实偏置/PDK R已进入多个模块；尚未成为同一套原生PLL、TX实际发数、RX/CDR动态系统网格。tt/hh/ll也不等于完整RC包络，理想电容不会自动随库段变化。
- 局部失配已有偏置、CTLE、采样器/理想校准数据；PI主要为传播模型；TX、PLL和物理读出尚缺当前版本的MC。模块结果与整颗良率分开。
- VCO已有7点器件噪声/系统模型，偏置已有噪声和PSRR表征；原生闭环噪声、附加时钟抖动、共享参考和真实供电尚未整合验证。
- 偏置有上电测试，B2有预充测试；统一的ready→PLL捕获→RX校准→训练尚未通过整链验证。
- 版图提取寄生、数字库映射/STA、CDC、真实封装/回流和系统统计BER。
