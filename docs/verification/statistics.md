# 统计与蒙特卡洛

失配、修调和良率的做法。工艺角处理全局偏差（同一颗芯片上的器件一起偏），MC 处理局部失配（相邻器件之间的随机差）。两者分开做，再按判据类型组合。

## 三层

| 层 | 例 | 有无规格 | 怎么得到分布 |
|---|---|---|---|
| 器件参数 | Vth、R、β | 无（只是输入） | 卡片：[mismatch_card](../../analog/common/devices/tb/mismatch_card/card.py)（Pelgrom 系数） |
| 模块指标 | 采样器失调、Vbg、PI INL、占空比 | 有，或有分配的预算 | 模块 MC（`<corner>_mm`），或参数分布 × 灵敏度传播 |
| 系统判据 | 位中心裕量、BER、窗口、摆幅 | 有 | 判据的联合概率（下节） |

器件参数超出某个范围不是失败；模块指标超出分配的预算也不是失败——只有系统判据决定。预算分配是设计手段。

## 判据类型

- **串联判据**：每个实例都必须过，失败就是功能失败（4 个采样器的失调、64 个 PI 码每一步为正、每个 DFF 的时序）。芯片良率 = 各实例通过率之积（独立时）；实例越多，单个要求越严：N 个实例要合计 99.73 %，单个要约 1 − 0.0027/N。
- **传播判据**：一个系统量由多个参数决定（Vbg 由失调、电阻比、PNP 决定；vcm 由 Vbg、分压比、缓冲失调决定）。独立随机部分平方和：σ² = Σ (∂f/∂pᵢ)² σᵢ²；独立误差平均掉（大器件 = 多个小器件的平均，这就是 Pelgrom 的 1/√面积）。
- **相关部分不平均**：全局工艺偏差、温度、电源对同一颗芯片上的器件同向，用工艺角最坏情况线性叠加；靠比例结构（恒摆幅偏置、带隙、匹配转换）消掉。
- **软判据**：规格允许变差的量（高低温 BER），记录分布，不按串联判据卡。

## 预算

总要求 b = 系统性部分（PVT，线性） + k·√(Σ Sᵢ² σᵢ²)（随机部分）。满足它的 σᵢ 组合很多，按代价选：失配受面积限制时 σ 减半面积 × 4，分配到各项"每压一点 σ 的代价"大致相等；某项代价陡增时改用修调 / 斩波 / 校准，而不是继续加面积。

**修调**：每颗芯片的失调是静态的，修调去掉它；MC 用来定修调范围（覆盖 3σ 及以上并留余量），修调后的残差 = 步长 / 2 + 修调后的温漂与老化。范围不够时修调饱和而不是失败：残差 = 失调 − 范围，仍按系统判据计。

## 样本数与报告

- 默认 200 个样本（每样本几秒的模块约 20 分钟）。正态指标用容差区间：200 个样本、覆盖 99.73 %、置信 95 % 时 k = 3.28（[`stats.k_factor`](../../src/serdes_flow/stats.py)），即估计 σ 的不确定性多收约 10 % 余量。报告 mean、σ、偏度、峰度和 3σ 容差区间；|偏度|、|超额峰度| 接近 1 时不要外推到 3σ。
- 通过 / 失败型（启动、亚稳态）不是正态：计数，用 Clopper–Pearson 区间（997 / 1000 → [0.991, 0.999]）；要证明更小的失败率需要更多样本或重要性采样。
- MC 在哪些 PVT 点做：见下节。不同时叠加库的 `mc` 段（全局随机工艺）和工艺角：全局偏差已由工艺角覆盖。

## 失配与工艺角怎么组合

**失配的大小与工艺角无关，灵敏度有关。** SKY130 每个工艺角引用同一份失配文件：`vth0 = 该角的名义值 + MC_MM_SWITCH·AGAUSS(0,1)·slope/√(W·L)`（例：`sky130_fd_pr__nfet_01v8__mismatch.corner.spice`，`slope` 对所有角相同）。工艺角是整片芯片的平均偏差，失配是同一片上相邻器件之差，来源不同，模型里相加且独立，所以 SS 角上的局部偏差仍围绕 SS 对称（不是"向 tt 强、向 ss 弱"）。若代工厂的角是用单管总散布做的，角上再叠 MC 会重复计入、偏悲观；SKY130 库看不出角的来历，按独立处理（偏保守）。

不独立的是电路对失配的灵敏度：同样的 ΔVth，过驱动小、再生慢的角折算成的失调更大（采样器 σ：TT 5.7–6.7 mV，SS 1.65 V 85 °C 6.3–7.3 mV）。判据是每个角都要带着失配通过：裕量(角) − k·σ(角) ≥ 0。

做法：

1. TT 上 MC（200 样本），得到 σ 和主导器件；
2. 在裕量最紧的 1–2 个角再做一次，看 σ 怎么变；
3. 其余角用确定性的"失配角"代替 MC：回放 MC 里最差的几个真实样本（下条），或从灵敏度构造最坏方向（ΔVth_i ∝ σ_i² S_i，合起来正好 kσ）。45 次确定性仿真代替 45 × 200 次。前提是响应近似线性（偏度小、两个角上主导方向不变）。

**配对 MC（同一颗芯片换条件）。** 同一 deck 只改温度 / 电源 / 修调码时，同一 `setseed` 的第 k 个样本是同一组失配，可以逐样本比较（修调后的温漂、失配角回放）。工具要求：`serdes_flow.mc` 在 `setseed` 之后先做一次 `mc_source`，丢掉读网表时抽的那组（它不受种子控制）；2026-11-03 之前的运行每个分块的第 0 个样本属于这种，配对比较时须剔除。

**修调后的温漂。** 修调码在一个温度定下，修正量在别的温度按修调步长的温度系数缩放，失配本身也随温度变（早期采样器实测：同一样本 85 °C / 27 °C 为 1.06 倍，−40 °C / 27 °C 为 0.91 倍，另有 σ 0.7–0.9 mV 的随机变化）。修调结构要让步长的温度系数接近失配的温度系数；当前主线采样器失配与修调裕量见 [RX CMOS v2 / 5G](../design/rx_cmos_v2.md)。

## 执行、续跑与成本

采样器、CTLE、带隙和偏置分配的 MC 入口统一使用 `mc.run_many`。完成条件包括退出状态、计划行数和列结构；瞬态 deck 传 `t_end`，每行写实际结束时间，避免截断瞬态被早期 crossing 误判为完成。测量未找到 crossing 是 NaN 观测，需要分析量程/功能原因；有意保持不翻转的路可以有 NaN。求解完整、测量完整、满足规格是三件不同的事。

`--reuse CAMPAIGN` 保持原参数、种子和分块大小，已完成且输入一致的块直接使用，缺失/失败块在 `.rN` 新目录重跑。输入哈希清单覆盖 deck、递归 include、复制激励与 PDK 安装标识；旧结果没有清单时重跑到新尝试。PDK 按安装标识视为不可变。采样器最差路只统计参与路均有测量的样本，另报不完整样本数；存在缺失时不能当作全部样本的良率证据。

**采样器的新默认值为 `--chunk 8 --workers 3`。** 修调采样器三样本实测进程大小增量约 115–144 MB/样本，旧默认 50 可能超出 3 GB 限制。默认变动会改变分块后续样本身份：配对旧 MC 或加载旧修调码必须显式指定原 `--chunk`，例如原来为 16 就继续用 16。不同拓扑/随机实例顺序之间，同种子不保证同一组物理失配。

```bash
# 只读：样本进度；深查成本和输出完整性
uv run python -m serdes_flow.watch results/analog/rx/sampler/offset_mc/RUN_ID --every 600
uv run python -m serdes_flow.audit results/analog/rx/sampler/offset_mc/RUN_ID

# 小规模、相同随机样本对照，rusage 保存每样本求解/内存指标
uv run python verification/mc_profile.py --samples 3
```

`mc.deck(..., profile=True)` 输出 `rusage all`。分块大小应由当前 DUT/时间窗的内存增量决定；并发最多 4 个，多个 campaign 合计也不得超过 4。默认是保守起点，不是任意机器上不会 OOM 的保证。实测增量：PLL ÷8分频器（真实偏置、PDK R、48 ns瞬态）约165–200 MB/样本；`spice.run`的3 GB上限下一块最多约15个样本。2026-11-08按25样本/块×4并发运行时，每块都在第18个样本被上限杀掉（run_many反复重跑、无一完成），4个进程合计8.4 GB，同日的虚拟机停机也发生在这一运行中。被截断的块可回收：样本k由种子固定、截断只由内存决定。

当前r6 VCO局部TT失配pilot（完整PDK、真实BG/定宽R、四个30fF buffer、24ns；`results/analog/pll/vco/mismatch_r6/20261114T133455.717022Z`）的两块实测一致：第1–4样本程序大小约532/778/1024/1270 MB，追加样本约246 MB，而非旧45 MB估计。本轮固定chunk4、单worker；该测量不能替代分频或更大闭环DUT的成本。输入与初筛范围见[VCO失配卡](../../analog/pll/vco/tb/mc/README.md)。

## SKY130A 失配与高阻多晶硅热噪声边界（PDK 实测核对）

以下 PDK 模型行为已在 SKY130A + ngspice 47 上实测核对，涉及 LDO、偏置、参考源和噪声敏感电路的 MC 与噪声仿真时必须遵守：

- **局部失配与全局统计开关互不自动合并**：`sky130.lib.spice` 中 `*_mm` 库段设 `mc_mm_switch=1, mc_pr_switch=0`（仅开局部失配），`mc` 库段设 `mc_mm_switch=0, mc_pr_switch=1`（仅开全局统计），两者不会自动合并。
- **高压 5 V MOS 阈值失配与 `nf` 缩放边界**：`nfet_g5v0d10v5` 与 `pfet_g5v0d10v5` 的直接 `vth0_slope=0`（仅 `toxe` / `voff` / `nfactor` 含随机项），不可直接宣称具备直接阈值失配覆盖；`nfet_05v0_nvt` 含 `vth0_slope=0.0012`。MOS 包装子电路的随机失配因子按 `sqrt(l*w*mult)` 缩放，无独立 `nf` 因子。
- **MIM 电容并联参数陷阱**：`cap_mim_m3_1` 的 `mf` 仅进入随机失配项分母而不乘名义电容，并联多个 MIM 必须显式实例化（不可仅靠 `mf` 扩充容量）。
- **高阻多晶硅 `res_high_po` 与 `xhigh_po` 热噪声实测差异**：`res_high_po` 源模型虽标有 `isnoisy=0`，但 ngspice 47 忽略该参数，普通 `high_po` 存在正常热噪声（实测 1 kΩ 等效 1012.68 Ω，32 串 31.25 kΩ 等效 1.0007 MΩ）；而行为电阻主体 `xhigh_po` 名义 1 MΩ 在 ngspice 47 中等效热噪声仅 159.75 Ω（严重低估），噪声敏感路径应避免使用 `xhigh_po`。

## 模型局限

- SKY130 的 PNP 模型没有失配项；带隙中 VBE 失配只能按文献估计。
- 测试台的负载电阻多为理想电阻，电阻失配和电阻角只有换成 PDK 电阻后才进入仿真。
- 噪声（随机抖动）不是失配，见 P4。
