# WP-004 字入口固定相位约束

对六个实测条件，在额外字时钟接收/缓冲延迟为零的假设下，固定相位所需最小窗口如下（ps；由 `evidence.json` 的 `observations` 中各组 `minimum_window_ps` 计算）。实际更新窗未知，这些值不是设计验收。

| 单元 / 延迟 | 六条件 | FS 两条件 | SS 两条件 | TT 单条件 | FF 单条件 |
|---|---:|---:|---:|---:|---:|
| lean tcq | 122.683 | 54.890 | 42.973 | 15.560 | 7.960 |
| lean clock→CML | 189.691 | 53.349 | 64.791 | 19.802 | 9.340 |
| reset tcq | 510.886 | 69.305 | 207.373 | 48.524 | 26.868 |
| reset clock→CML | 571.620 | 77.994 | 215.774 | 48.445 | 29.002 |

跨六条件扫描中，lean tcq 从 W=150 ps、lean clock→CML 从 W=200 ps、reset 两项均从 W=1000 ps 起有非空交集。所有档位的交集和每个端点见 `evidence.json`；416 个可行交集端点经 balance 检查，最小计算余量 0.738 ps。失配与 tap error 均设为零，未评估失配；balance 内部 GRID 只重复同一确定值，不是 45 个独立 PVT 观测。相位交集端点相差不超过 1e-9 ps 时归一为相等，此容差仅处理浮点舍入；零宽交集为零余量，不表示设计有裕量。

输入 `docs/data/tx_ingress_card.json` 的区间已合并两种静态 MUX 加载、上升和下降数据；负载与边界见 `docs/design/tx_ingress.md`，连接和旧激励见 `docs/work_packages/deliveries/WP-002/evidence.json`。字周期 4000 ps、UI 250 ps；跨工况绝对延迟变化不是随机抖动或 0.15 UI 边沿散布。未插值未测角，真实字时钟路径及 PVT、实际更新窗、动态位映射和跨字一致性均未知。两组 8 位透明/保持结构带来新负载和同沿保持竞争；本 card 的 clk→q 最小值不能证明改负载后的保持。需后续局部电路与动态模型。
