# 三个跨温数据不足组合的分辨率取舍

**结论：现有数据不足以判断半码步长能否在 CP 上沿窗口提供跨三温冻结码，也不足以证明必须拓宽细调或重新捕获。** 需要补测覆盖候选码与 CP 上沿的 VCO 点，再评估实际半步电容阵列。历史扩展记录未在这三组中找到跨三温离散码，但候选码测量不完整；既不能断言离散固定码无解，也不能推广为连续码没有交集。

用现有实测频率在码轴上对 1/f 作分段线性插值，按 0.85–1.35 V 窗口估算的三温交集分别为：

| MOS、1.95 V、无源角 | 下界码 | 上界码 | 判断 |
|---|---:|---:|---|
| FF、tt | 6.049 | 5.780 | 空 |
| FF、ll | 11.016 | 10.070 | 空 |
| FS、ll | 6.289 | 5.242 | 空 |

这里下界和上界分别由各温度 0.85 V、1.35 V 的 2 GHz 码轴交点求最大值和最小值；假定频率随码单调递减、随细调电压递增。它们是相邻已仿真整数码之间的模型插值，非实测连续码或电路保证。若只保留此较窄窗口，半码不会修复交集；不能据此判断更宽 CP 窗口。

三个组合的 CP 上沿实测为 1.60–1.66 V。VCO 扩展数据最高到 1.50 V，且各温度现有 1.50 V 点全部高于 2 GHz，没有在码轴上夹住目标；因此无法用现有点内插上边界。`workmap.py` 的 `numpy.interp` 在超出 VCO 采样电压时采用端点值，既不提供真实 CP 上沿的频率，也不是线性外推。原 `extend.json` 的离散码结论按此实现读取；没有上沿频率时不能把它当成更高电压的完整覆盖或证实连续交集为空。

[数据](resolution_tradeoff.json)包含九个条件的离散测点、CP 上沿、各电压下局部 1/f 二次拟合的系数及逐电压最大/平均相对频率残差、可重复输入路径与 SHA-256。拟合仅作诊断，非实际测量；1.50 V 未夹目标时不外推根。`uv run python verification/work_packages/wp006_pll_coarse.py --tradeoff` 重建。

补测应包括每个温度在接近候选半码两侧的整数码、1.50 V 至各自 CP 上沿的实际 VCO 调谐点，以及候选半步的真实五位阵列；同时确认细调单调性、负载、CP 动态窗口及切码/再捕获行为。若补测后连续交集为空，才有依据比较扩大可用细调范围与允许重新捕获；即使模型交集含半码，也需实际电路和动态验证。
