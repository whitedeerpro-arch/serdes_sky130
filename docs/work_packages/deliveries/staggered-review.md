## 极性、位序与保持

- 保存 deck 中 `sp > sn` 对应 clk 高。MUX 快照以 `sp` 支配 B 尾支路、`sn` 支配 A；每个 `Xm i` 的 A 接 lane i、B 接 lane i+8。原型 A 锁存器高透明低保持，B 低透明高保持，因此低半周期选 A、高半周期选 B 时所选组保持；16 个 DFF 均为上升沿捕获。这个判断依赖 deck 所定义的时钟极性，接真实接收器后须重新核对其输出相位、传播延迟与 MUX 选择交越。
- 字 k 在上升沿捕获后，先于下一下降沿把低 8 位送到 A，再于下一上升沿选高 8 位 B；后一上升沿同时捕获字 k+1，B 必须在新数据到达前关闭。测量把每个 MUX 中点的 `z[i]` 与 `z[i+8]` 分别组装成字 k 的对应位，八个输出字均等于预期。这证明所选测试字下首级输出的局部对应，后续级顺序、完整 16 UI 位序和跨字边界仍需独立检验。
- `hold_from=edge−100 ps` 至 `edge+1.9 ns` 内逐点检查 Q 的符号裕量大于 0.3 VDD、CML 输入差分符号正确，且在 `edge+1 ns` 对 MUX 输出取样；这是按**预先指定的理想选择沿与窗口**验证波形，不是从实际 MUX 选择交越推导的保持窗口。MUX 输出只检查中点，未证明切换边缘无毛刺或整个实际选通区间有效。
- B 关闭到下一字数据的最小间隔用内部 `clk_b` 和 `h8…h15` 的 VDD/2 交越计算，六条件最小为 53.87 ps（FF 冷角）。这不是锁存器建立/保持孔径或可用时序余量：门控晶体管的有效关闭并不等同反相时钟中点，且未扫描数据/时钟相对位置。只统计发生翻转的 lane，缺失交越记录为 null，最小值会忽略 null；应将预期翻转缺少交越显式视为测量失败。现有功能检查虽检验已选周期输出，不能替代孔径扫描或证明所有变化组合。

## 后续签核边界

实际接收器和扇出接入后，测量真实 CMOS 与 CML 选择交越、相位偏差及占空比，按实际选通区间验证全部 lane，并扫描输入建立/保持与 B 关闭竞争，覆盖两种数据方向和字切换。完整串化链须同时检查眼图、逐位映射和跨字边界。定义上游字时钟、同步/CDC、valid/flush 与无复位启动策略；本局部同步激励不证明 CDC 安全。最后覆盖 45 个 PVT、实际负载及失配、噪声/抖动；六个压力点不能当成全角签核。
