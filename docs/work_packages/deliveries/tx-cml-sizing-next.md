# I-17：TX 内部 CML 局部尺寸下一步

先用同一完整 TX 观测窗口按实例归类，再从**非再生的时钟缓冲器**开始做小范围局部卡片；计数器、数据树和末级保持锁存器分别处理。最终 c2g 的 WT16/R240 只改变输出驱动级，不能推断上游计数器、时钟支路、数据/保持节点也满足 400 mVpp 上界。针对其他节点，目前没有本计划可引用的完整逐节点包络结果，不能预先指定哪些实例超标或宣布 I-17 已关闭。

[规格](../../overview/spec.md)对内部 CML 指定 400 mVpp 上界、150 mVpp 硬下限和 ≥200 mVpp 设计目标，并要求跨 PVT 下一级完整翻转。必须保留共模、时序、功能、眼图和位映射；数据节点受码型影响，不能用单一窗口的整体峰峰值证明最低幅度或跨 PVT 通过。

## 已知边界与不能盲扫的方向

- [最终时钟尺寸实验](../../design/tx_final_retime.md#2-ghz输出摆幅与时序联合选参)在两个 TT/FS 事件的实际末级加载切片中，WT16/R240 得到约 344–369 mVpp，但实际 A 关闭提前约 10–13 ps，FS 关闭时 g3 裕量从 53–57 mV 降至 33–36 mV；WT18/R240 的 TT 约 415–417 mVpp，超过上界。该实验是局部回放，不代表其它节点或全 PVT。
- [末级数据历史试验](../../design/tx_serializer.md#观察)中旧 r2 FS 热角单独把末级 R 从 400→330→270 Ω，位中心裕量约 121→88→39 mV，270 Ω 失败；下降坡约 18 mV 不随摆幅消除。现行重定时拓扑不同，数值不能直接移植，但足以排除把“全树只减 R”作为无约束盲扫。应同时看真实 bit mapping、孤立位/长连码、保持差分和 ISI。
- [时钟分发](../../design/tx_clock_distribution.md#s4-电路分发-v3)的 S4 计数器 W20 保持管与旧分频打拍器 W20 并非同一结构；后者 FS 热角发生主从穿透，不能把其失败简单归因或推广到当前计数器。直接弱分频抽头作时钟曾使锁存器透明；S4 的实际 FS 热角内部时钟约 265 mVpp。另一次稳态计数复核为 14/15 连续，FS 热角窗口开头曾 3→0；不能用初始辅助的稳定计数代替启动证明。
- [balance 模型](../../../src/serdes_flow/balance.py)与 [TX 结构分析](../../../analog/tx/clock_distribution/theory/clock_structures.py)给出相对时序/旋钮余量，S4 在旧 15 个 V/T 拟合假设下触发器 clk→q 放大约 4.1 倍、门 3.6 倍、对中 buffer 约 1.5 倍，见[结构比较](../../design/tx_clock_distribution.md#时钟构造结构比较)。这些系数**不是**允许的电流/尺寸缩放倍数，也不保证再生、摆幅、输出共模或实际建立/保持。用它筛掉时序无解方案后仍须通过测量校准。

## 最小可派发步骤

1. **建基线，不扫参数。** 在明确登记的完整 TX 波形，先核对现有 [envelope 工具](../../../verification/plotting/tx_cml_envelope.py)的来源、完整性和 40–100 ns 窗口，按 `q0/q1/q2`、计数器 `d/m`、`kc/kr/r2g`、`c250/c500/c1g/c2g`、输入转换器、g1/g2/g3、A/B held、串化输出分组列最大摆幅、差分极值、共模、观察到的两极性。时钟额外列逐完整周期最小摆幅；数据节点下限不评分。`s2g` 是规定的上游边界，不把它当作 DUT 输出通过。使用已验证的相同负载和工况 TT、FS 热、SS 冷；如候选 WT16/R240 的来源未通过接口 collector，则保持缺失，不以时钟观测代替。
2. **非再生 buffer 局部卡。** 由第 1 步确定超上界的一个实际支路，以原级数、输入器件宽度、前后真实扇出/寄生代理和 PDK R tt 为基线，保留输入及负载签名；先比较原样与尾宽约 −20% 及名义 R 约 −20% 的两个独立扰动，再按实测电流/幅度确定是否值得联合调整。百分比只是测局部灵敏度，不是预测合规尺寸；电阻几何/实效值及 Vds 需单独实测。记录过零、上下沿、幅度、共模、功耗及所有相邻路径延迟；用 balance 模型检查分支相对相位，再回到实际级联验证。不可默认共同缩小所有缓冲或改变已调好的 extra3 相位。
3. **计数器局部卡。** 如 q、m、d 超幅，先固定 `whold`、latch 反馈结构、时钟 follower 和外部负载，在原样附近对尾流与 R 做与上一步同样的两个独立小扰动；不要一开始同时修改再生管和时钟。用实际输入轨迹/负载分别检查 8 状态全序列、主从穿透、最小逐周期幅度、clk→q、次态建立/保持和恢复时间；设置边界与已有 [counter.py](../../../analog/tx/serializer/tb/clock_replay/counter.py) 的压力角口径可比较，但无需重跑旧全链。若减尾流导致再生过慢或锁存透明，停止该方向并用结构比较探索隔离/分支驱动，不能放宽功能门槛。
4. **数据树与 held 分开。** 对第 1 步实测超幅的最低层级，先以对应前级输入、下级源跟随器和真实偏置/负载切片复现原样；输入转换器、g1–g3 与最终 latch/MUX 单独设旋钮。保留当前末级保持管 `whold=40`、`latch_tail_scale=2`、`latch_load_scale=0.75` 作为基线（[单元](../../../analog/common/cml_mux/spice/cml_lowov_cells.spice)），不要通过缩小保持管简单消摆幅。对非再生树的 R/尾宽先做单轴小扰动，再根据测得的共模、增益及负载观察约束决定组合；最终 held 则先测再生恢复、开关时序及数据建立/保持，必要时同时探索分离再生增益与输出幅度的结构。若现有结构的幅度上限和眼图裕量冲突达到中等修补难度，同步比较替代拓扑。
5. **分层收敛后再联合。** 对每个候选在 TT、FS 低压热、SS 低压冷先测真实偏置与 PDK R，独立记录失效/截断与有界重试；若局部改善且不破坏建立/保持与相位，才登记新边界并送完整 TX 重测眼图、完整位序/跨字映射、计数与逐节点上限。随后扩展 45 PVT、电阻角、源阻抗、失配、噪声及上电，不能将单窗、少数码型的观察转为全部规格合格。

## 模型与记录要求

以 [尺寸设计流程](../../verification/sizing.md) 的 `I×R`、`gm/C` 和实测卡作起点：先测同工况尾电流、单端电阻的实际 PDK 值、各管 `Vds−Vdsat`、输出差分/共模及负载，保留有限增益与不完全换向；两个扰动分别校准幅度和延迟的局部灵敏度，再预测一个联合点及残差。`I×R` 仅是初筛，电阻角、温漂及源跟随器工作区改变都会破坏简单比例。对每个点记录来源快照与哈希、激励/负载、求解与测量窗口、规格量及未分级项；功能错误与数值截断分开，任何缺失不能标通过。
