# 末级物理时钟链：局部回放比较

在记录的 TT、FS 各两个事件中，额外时钟缓冲由 1 级增至 3 级后，实测 c2g 下降沿相对原链延后约 31 ps（TT）或 39 ps（FS）。FS bit 48/104 在固定源训练相位加实测相位差处，输出目标极性差分由 19.3/68.0 mV 增至 136.9/186.1 mV；TT 对应从 170.1/218.4 mV 变为 168.7/217.2 mV。这是局部回放中值得进入完整 TX 验证的候选，不是全码型或规格通过结论。

原链 count 1 的四个事件均通过 c2g、qp/qn 和两组保持节点共八节点的 ≤5 mV 校准，最差误差 0.1115 mV。数据为 `docs/data/tx_final_clock_chain.json`；图为 `docs/figures/tx/ingress/tx_final_clock_stage_comparison.png` 和 `.svg`，来源 `results/analog/tx/final_clock_chain/20261107T094939Z`。无参数运行 `uv run python verification/plotting/tx_final_clock_chain.py` 可从小数据重画。

## 范围及采集复核

每支路依次包含相同的入口隔离器、1/2/3 个额外缓冲和输出缓冲，分别对应总共 3/4/5 个缓冲器。三支路由同一理想记录电压驱动，代表独立数学实验；它们不复现上游源阻抗或反馈。范围只覆盖 TT、FS 各两个事件，不覆盖全位、45 PVT、噪声、失配或完整 TX。参考保持时刻为原始实际 A 关闭时刻加实测 c2g 相位差再加 200 ps，是估计时刻，并非候选支路实测 A 关闭沿；末尾 200 ps 排除。

采集器逐支路在半字事件后 0–500 ps 选取首个 c2g 下降交越，直接减 count 1 同事件的交越；没有逐级延迟求和或用载荷拟合相位。输出采样使用原始训练延迟及上述实测相位差。采集器检查边界、checkpoint、来源 trace、各 raw 和执行记录的身份与完整性，并重新测量基线；哈希错误直接报错，基线失败项保留并明确标记为不可解释，不被静默丢弃。
