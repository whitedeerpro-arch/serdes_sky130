# TX 内部波形：定位方案

当前证据只定位到 FS 热角完整 TX 的 slot 8 低裕量及 slot 0 marker 异常，不能把根因归给某一级。新追踪必须先验证与归档原波形的共同节点一致，再比较各级在实际选择窗口内的响应；没有响应变化时不报告虚假的传播延迟。

## 边界和连线

两条追踪复用 TT `20261107T044921Z`、FS `20261107T051545Z` 的电路、真实偏置、理想 2 GHz 源和 RTL 事件输入，仅追加观测并结束于 60 ns。它们不覆盖原 120 ns 全部载荷；bit 232 若超出波形必须标记未覆盖。比较训练 marker bit 48、载荷 bit 104，及仅在实际覆盖时的 bit 232；按归档 capture 的有效字重建位序，并使用源 summary 从实际 A 选择沿得到的 sequence start，不拟合相位。

`serializer16_retimed_lowov.spice` 的首级 `r1_0` 选择 lane 0 或 8，输出 g1_0；第二级 `r2_0` 选择 g1_0 或 g1_4，输出 g2_0；第三级 `r3_0` 选择 g2_0 或 g2_2，输出 g3_0；末级先分别保持 g3_0、g3_1，再选择 ah、bh 到 qp/qn。其余支路是同构的交叉半字配对。CML mux 局部输入 `sp>sn` 选 B，`sp<sn` 选 A；实际芯片时钟分发和本地源跟随器可能改变所见极性和延迟，须从实测差分节点确认，不能把逻辑计数极性直接套到每一级。

q2 下降对应 7→0，上升对应 3→4。按目标位序，slot 0 是半字 A 起始，slot 8 是半字 B 起始；它们共享首级 lane 0/8 的交接，但末级保持及其它 rank 的选择相位不同。对每个事件，以实际 c250 差分交越为时间零点，先识别其方向、q2 状态以及各 rank 的实际局部选择，随后建立从对应源字到输出位的时间线。A/B 选择沿与对应 bit 中心之间的距离须从波形计算，不预设沿恰好位于位边界。

## 检查次序

1. 核对 deck、激励、负载及原始与追加观测的公共节点：波形有效终点、c250/c500/c1g/c2g、qp/qn 与远端，报告交越和振幅差；额外保存本身不等于结果可比。
2. 画 TT 和 FS 同一 bit 周围的事件波形：lane 0/8 转换器差分、g1_0、g2_0、g3_0、末级 ah/bh、qp/qn；同时展示四路时钟、首级 slp/sln、tail/ta/tb、末级 sap/san/sbp/sbn 和 bias。标注源字的 lane 0/8 值、事件边沿、输入标称中心与依据归档训练延迟固定得到的输出采样中心。首级 tail/ta/tb 和偏置以窗口极值与选择沿采样值补充记录。
3. 报告窗口内每个差分信号的零交越相对 c250 沿的时间，列出交越方向和局部选择状态。追踪实际被选支路的输入和输出及其建立/保持窗口；无交越可能是相邻值相同或波形未跨零，不能解释成零延迟或失败。各 rank 同时承载不同位，不能把同一时刻的所有 rank 值直接互比。
4. 首个错误或缓慢节点仅在其预期输入位、选择窗口、前驱稳定及输出阈值都可判定时提出；标注实际有效窗口、局部交越时间、振幅及 TT 对照。若无法区分数据、选择、保持和偏置影响，记录为未定位，不能仅凭相关性认定根因。

这些波形是两工况局部诊断，不构成 45 点规格或新设计通过结论；不改变数据相位、负载或电路，不执行新仿真。
