# TX 并行入口动态失败诊断

FS 1.65 V、85°C 的低裕量集中在每字第 8 槽，而不是所有槽普遍塌陷。串化器第 8 槽最小有符号裕量 0.52 mV，其他槽最小值为 111–133 mV；pad 和远端第 8 槽分别为 29.4、33.6 mV。三个节点的最差载荷样点均为 bit 232，同槽 bit 104 和 296 也偏低。TT 串化器各槽最小值为 154–164 mV。FS 远端的训练 marker bit 48 错误；串化器和 pad 的 marker 无错误。位序/眼健康指标及遗漏、额外过零仍应与原 summary 一起阅读，不能把零载荷误码当作规格通过。

这些观察支持优先检查 B 半字边界及其选择路径，但不能证明根因：bit 8 的现象也可能受到该码型、节点和相邻路径的共同影响。现有波形未保存 CML 转换器输出和串化树内部节点；不能用输入引脚的先行时间推断整个路径的动态裕量。按 changed lane 的最近一次 50% 供电电压交越统计，FS 的 q 到所选 A 下降沿或 B 上升沿为 1137–1305 ps、转换器 `din_b` 为 1100–1256 ps；TT 分别为 1308–1435 ps 和 1271–1402 ps。数值描述的是最后交越到边沿的时间，不是经完整 setup/hold 约束验证的余量。

参考实际 c2g 上升过零，FS c250 下降沿在训练和载荷中分别为 23.45–24.02 ps、24.04–24.45 ps；TT 为 29.82–30.37 ps、30.21–30.48 ps。该边沿后 30 ps 的计数器 q0/q1/q2 均为 000；其他分频沿与训练/载荷状态计数保存在 JSON。这些结果表明此观测窗口内没有明显的计数器状态变换，但不证明内部相位或脉冲宽度满足要求。

下一步局部测量应在相同 FS 激励和边界下保存转换器差分输出、半字选择和串化树逐级节点，定位 bit 8 附近波形首次劣化的位置，并对照同码型 TT；先核查有效窗口和脉冲宽度，再决定电路改动。不得通过拟合载荷相位把失败调整为通过。

诊断文件为 `results/analog/tx/parallel_diagnostic/20261107T053336Z/diagnostic.json`。脚本检查归档与生产者哈希并独立重算 `serial.check`，记录各槽采样裕量、边沿残差、最差位、marker 错位、各 changed lane 的 q / s / din_b 先行时间以及各时钟沿相位。复现时会追加新目录，不运行仿真：

```bash
uv run python analog/tx/input_register/tb/full_serializer/diagnose.py \
  --campaign results/analog/tx/parallel_serializer/20261107T044921Z \
  --campaign results/analog/tx/parallel_serializer/20261107T051545Z
```

范围为理想 2 GHz 源、真实偏置和 PDK tt 电阻、初始化计数器、RTL 事件模型标签；非完整 PVT、噪声、启动或失配验证。所有时间/相位定义见 JSON。
