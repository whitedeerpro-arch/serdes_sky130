# TX 入口与串化返工分类复核

当前 v3 完整链 TT 动态点的位映射为 identity，**不要把旧 r2 八状态 remap 接入当前 v3 路径**。现有证据支持继续验证当前电路，尚不支持把激励/初态问题一概判成电路缺陷，也不构成 45 条件或启动签核。

## 映射证据与适用域

[v3 计数器](../../../analog/tx/clock_distribution/spice/tx_clock_counter.spice)是共同时钟的三位同步二进制计数器，q0/q1/q2 分别是 1 GHz/500 MHz/250 MHz；[分发代码](../../../analog/tx/serializer/tb/clock_replay/variants/dist_v3.py)按此直接派生各路。稳定二进制计数时，q2 上升对应 `3→4`，下降对应 `7→0`；本次数据帧从 CML 250 MHz 下降、选择低半字 A 时开始。低两位相对 q2 的关系由同一计数序列约束；计数初相可能改变绝对字起点，并不等价于 r2 的独立分频器状态。实际波形仍须验证各级反相、传播相位与计数未错步。

旧 [r2 置换表](../../../digital/tx/tb/data/serializer_state_permutations.hex)以独立的 `{c500[1:0],c1g}` 为索引，八个状态中只有状态 0 为 identity。`tx_ingress_preprocessor` 固化的是该表与锁存状态的控制契约，适合未来需要旧 r2 逆置换且状态定义已核实的边界；它不是 v3 状态检测器，当前 v3 不采用。即便选择表中 identity，也不能据此证明状态检测或其他角点物理映射。

`parallel_serializer/20261107T044921Z` 的 [plan](../../../results/analog/tx/parallel_serializer/20261107T044921Z/plan.json)和 [summary](../../../results/analog/tx/parallel_serializer/20261107T044921Z/summary.json)固定 TT、初始化计数器、真实 v3 分发/入口/串化及驱动，理想 2 GHz 源、真实偏置和 R tt：175 个计数样本无错步，22 个有效字，输入边界和半字保持通过；serializer、pad、remote 均 256 payload bit 零错、位映射 0–15，远端散布约 0.034 UI、位中心最小有符号裕量约 194 mV。`run.py` 从输入捕获字构造逐位序列、用训练定位并分别测眼图和 `bit_mapping`；它回放 guard 而未接 preprocessor。标签仅是 RTL 事件源，不是物理标签路径。上述单点支持当前边界 identity，不能推广为全部 PVT 或无初始化启动。

## 分类与最小下一步

| 分类 | 判断和动作 |
|---|---|
| 电路返工 | 目前无证据要求因这些启动/回放失败重做入口 DFF 或保持 bank；保留两级数据延迟。B 关闭切片六角两方向已夹边界，距已测保持点最小 70.45 ps，仅为固定波形局部结果；若真实源阻抗、其他码型或失配暴露问题，再以单元可行区和备选结构确定尺寸/拓扑。物理 guard/标签与驱动 blank 仍需设计接入，并非现有回放电压源。 |
| 激励、边界、测量工具返工 | 历史 BC v1 长 PWL 参数溢出使电源停初值，v2 窗口截断及内部状态使原样校准失败；v3 保留前周期并先校准，12 组通过后扫描。首个接收器试验首字失败与高态初始接收器缺少真实捕获沿有关，后续预热才使六角局部数据成立。保留全部原始失败，不把它们改记通过。探针需登记物理负载与源身份，按生产时钟产生 schedule；消费端继续核对实际捕获相位、输入建立/保持及标签，绝不从串行输出拟合输入相位。 |
| 仍缺工程验证 | 先完成正在进行的 FS 热整链动态点，再按同一固定映射和各自登记边界扩压力角，分别报告连续计数、逐位映射、眼图、输入及半字保持；异常先归因，不按角调整映射掩盖。之后覆盖全部 45 PVT、源阻抗/负载、建立保持与其他码型、失配、噪声/抖动、真实 PLL 与未初始化启动、物理标签和驱动 blank，以及库映射和 STA。功能失败不可降格成规格通过。 |

证据范围还包括 [入口设计](../../design/tx_word_capture.md)、[保持扫描](../../design/tx_launch_hold.md)和[原始失败记录](../../history/tx_launch_characterization.md)。本次仅只读复核，未运行仿真或测试。
