# 输出级尺寸候选：probe 与动态运行的计数器初态

WT16/R240 的 TT、FS 两个动态运行均在捕获时钟对齐检查失败，不能作串化器通过判定。同条件 probe 与动态 deck 的 `.ic` 对三个 q 差分节点完全相同，但 `Initial Transient Solution` 中未约束的 m1/m2 主锁存节点不同；m0、q、计数器时钟及 replica 节点在日志所示精度内相同。这个事实与观察到的 1 ns 字时钟相位差相容，但尚不能证明主锁存初态是唯一原因。

这里比较四个 2 GHz extra=3、WT16/R240 归档的 `run/tb.cir` 和 `run/simulator.log`，数值为 ngspice 报告的初始瞬态解，单位 V，按日志有效数字抄录。probe 已记录字时钟相位；动态运行的捕获对齐失败使现有分析拒绝评分。相位差约 TT 2.987→3.987 ns、FS 2.174→3.174 ns（模 4 ns）；它不是对输出眼图重新拟合。

## 输入与初始电路差异

两种运行顶层的 Vdd、四个 `Vbias_i0..3`、250/500/1g/2g 脉冲及八个行为差分源、Vtxen、Vlcm 配置在同一条件下相同。初始解中 Vdd 为 FS 1.65 V、TT 1.8 V；四个 bias 控制源均为 0.7 V，四个脉冲源初值均为 0，差分行为源初值分别为 Vdd−0.35 和 Vdd−0.15；Vtxen 初值 0，Vlcm 为 0.9 V。`vbias`/`vgi_bias` 初值分别为 FS 1.09929/1.13072 V、TT 1.03891/1.06948 V，probe 与动态运行一致。

probe 的 16 个数据源为独立直流 0 V；动态 deck 用 16 个 PWL 电压源，均从 0 V 开始。动态 FS 数据首次离开零的斜坡从 20.263619 ns 开始、20.283619 ns 到高电平；TT 从 21.077865 ns 开始、21.097865 ns 到高电平，均晚于 18 ns。动态 deck 额外有四个 guard 元数据电压源，初值均为 0；其中 `guard_ready` 在 FS 12.163619–12.183619 ns、TT 12.977865–12.997865 ns 上升，早于 18 ns，不能把所有新增源都描述为 18 ns 后才变化。其余 guard 首次高电平 FS 为 20.283619–24.183619 ns、TT 为 21.097865–24.997865 ns 范围。

数据源的 DC 与 PWL 类型不同，且动态 deck 增加四个独立电压源和节点；即使初始电压相同，求解矩阵及数值路径也可能变化。**推测**是这种数值路径差异使未充分限定的主锁存落入不同初始解；当前观察不能区分 PWL 类型、元数据节点或其他差异，也不能推断物理上电概率。应使用固定相同 master+q 初值并分别匹配或改变元数据和数据源类型的短对照验证；失败的原始波形和对齐结论保持原样。

## 18 ns单因素对照

`results/analog/tx/clock_epoch/20261107T153055.310765Z`固定FS原记录、负载、源、偏置与PDK，四个18ns工况均完整，先保留默认冒烟。缩短后的dynamic_repeat在8–17ns的11个公共时钟/计数节点与原120ns最大误差均为0。给原静态probe仅增加四个独立DC0元数据源后，两次字时钟沿差不超过4.74e−18s，两个工况计数均连续；没有改变器件、数据或`.ic`。这是当前最小有效边界修复的依据。

另两个工况对m0/m1/m2也强制相同零态：两者字时钟沿差约0.429ps，但8–18ns内都出现两次无效递增（7→4→1，随后才连续计数），不能只因为相位接近就采纳该初值。完整master零态方案不采用。后续新probe保持原q初值，匹配真实刺激的元数据源拓扑，重新记录48ns边界并再次检查完整载荷；旧两条120ns捕获错位记录不评分为通过。[索引](../../../results/catalog/tx_clock_epoch.json)。
