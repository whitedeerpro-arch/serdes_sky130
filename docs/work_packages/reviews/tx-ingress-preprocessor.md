# TX legacy 调序适配器 review

接受为旧 r2 状态语义下的 RTL 适配器，不接入当前 v3 数据路径。原寄存式 `tx_word_remap` 行为保留，组合核共用原八张表；新 preprocessor 在未 ready 时锁存映射，ready 期间保持，数据没有额外寄存拍。

集成者独立审查 RTL、正向置换测试 oracle、状态切换和标签排空，并复跑归档脚本：`results/digital/tx/ingress_preprocessor/20261107T051801Z` 中旧调序器 512 字、新模块 438 项断言、两项 lint、Yosys 通用结构检查通过。Terra 首轮归档 `20261107T051717Z` 同样保留。输入、脚本与测试表均从源码快照运行。

只读返工复核中将 q2 上升误写成 `7→0`，集成者核查同步计数器后更正：上升 `3→4`、下降 `7→0`。这是文档复核修正，不改电路。当前 v3 TT 整链三节点实测自然位序；不能把旧 r2 逆置换表套用到该结构，亦不能把 TT 结论推广为全角。

本验收不包含标准单元映射、STA、CDC、clock_good/状态检测器、物理标签或驱动 blank。独立 guard 的后续物理工作不由 legacy 适配器回归代替。
