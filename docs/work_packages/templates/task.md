# 有边界的任务模板

复制所需字段到具体工作包或模块迭代；这是模板，未填写项不表示已分配任务。

| 字段 | 填写内容 |
|---|---|
| 任务、模块、里程碑 | 稳定任务名；所属模块；执行计划中的 M 编号；相关 I 编号 |
| 要消除的未知 | 一个可以明确判定的问题，以及为什么现在做 |
| 执行与复核 | 执行者、集成复核者；尚未领取时写未分配 |
| 输入与身份 | 源码/数据固定路径、修订或 SHA、实际驱动、源/负载签名、角点 |
| 可编辑范围 | 具体文件/目录，避免共享文件交叉写入 |
| 最小实验与预测 | 模型推导/对照方案；先做什么；哪种结果改变决定 |
| 资源 | worker、时限、campaign、`t_end`、seed/chunk、续跑命令；只读任务写0仿真 |
| 验收 | 测量点、窗口、单位、功能与质量门槛及其出处；无门槛量 ungraded |
| 停止/扩大条件 | 缺输入、身份变化、数值不完整如何处理；满足什么才扩网格 |
| 交付与影响 | evidence/summary/handoff 或模块迭代路径；预计影响的接口与状态页 |
| 接手 | 实际命令/退出结果、已完成与未做、运行中进程、未提交文件、下一动作 |

正式 WP 的 JSON 和状态仍遵循[工作包协议](../README.md)，由集成者在 [config/work_packages.json](../../../config/work_packages.json)登记。模板不引入第二份任务状态。
