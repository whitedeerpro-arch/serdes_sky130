# 只读教学快照

第一课五个文件逐字节复制自本项目已有反相器示例及版图工具；原始路径和SHA-256见`ORIGIN.json`。原文件未修改，检查器判定逻辑未修改。

另追加两份`inv_std2`折指原稿供DS-02复核。它们是捕获的未验收输入，存在外部D端口未接的反例，状态已在`ORIGIN.json`注明，不能直接当合格模板。`folded_variants.py`只在新副本修正端口并做几何VAR；原稿快照保持。

保留镜像目录是因为示例构建器按仓库相对路径导入工具。准备练习时从这里复制，避免依赖其他agent尚未入库或后来修改的工作文件。

这套快照只服务DS-01。`magicutil.py`使用本机PDK/netgen路径，`plot_mag.py`只作辅助预览，完整寄生电阻提取未在此快照里实现。主教材与出版图片由上层专用脚本维护，不能把练习检查当成生产签核。
